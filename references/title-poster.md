# 双层标题海报系统

只在用户明确要求文字、角色名海报、作品名、双标题、档案版或字体主视觉时读取。它是叠加在人物母稿上的可选版式层，不是新的主笔触、媒介或背景风格。视觉事实仍以 [视觉语法](visual-grammar.md) 为准。

## 1. 触发与默认

- “带名字、标题海报、加作品名、左边写、双标题、角色档案版、字体主视觉、文字必须准确”等明确措辞触发本系统。
- 普通“海报、人物靠右、留白多一点”不触发文字；没有文案时留白保持空白。
- 标题模式已经触发但输入里没有可用的角色名或主标题时，只问一个最短问题：“一级标题写什么？”不要用“原创女高中生”等人物类别充当姓名。
- 不在生成前强制展示菜单。用户主动问语言或版式方向时，最多给三个口语化选项。
- 一张图只选一个标题版式机制；文字不自动触发纸张、做旧、商业杂志、报纸、UI、徽章或完整场景。

## 2. 两级文字合同

最多两级，第二级可以省略：

1. **一级：角色名／主标题**。只选择一个短角色名、短台词或用户指定短标题，承担主要文字识别。
2. **二级：作品名／官方代号／设定编号**。三选一，视觉权重明显更低。

“编号”只指角色或作品设定中真实存在的标识，例如 `CODE:002` 或 `UNIT-02`；不代表随机序号、日期、时间、坐标或装饰数字。没有可靠编号就不添加。不得为了版式完整而补第三层小字。

文字来源按以下优先级：

```text
用户逐字提供的内容
→ 用户输入中的角色名或标题
→ 用户明确要求“按作品自动选择”时采用可靠官方形式
→ 信息不确定时回退到用户原始输入或省略二级
```

用户明确给出大小写、标点或空格时原样保留。不要自动加引号、署名、版权条、账号、品牌、水印或 `by xxx`。

## 3. 语言路由

- 用户指定英文、日文、中文或其他语言时，逐字服从，不擅自翻译。
- 用户未指定语言时，沿用其输入中角色名／标题的书写形式；“画明日香，做成标题海报”默认使用“明日香”。
- 只有用户说“按作品选择语言、语言你决定、用官方形式”时，才根据角色最可靠、最常见且适合短标题的官方识别形式选择英文、罗马字、日文或数字代号。
- 官方拼写、日文原名、罗马字或英文作品名没有把握时，不翻译、不音译、不编造，回退用户输入。
- 单张海报最多使用两种书写系统；中文、日文、英文不得三套并列。
- 日系动漫不等于默认日文。禁止用伪日文或不可读字符制造“日系感”。

常见合法组合：英文角色名＋英文作品名；日文角色名＋英文作品名；中文角色名＋英文作品名；英文角色名＋官方代号；中文角色名＋中文作品名。

## 4. 五种版式机制

### 侧边留白标题

人物占左侧或右侧约 50%–70%，一级标题进入另一侧连续纯白负空间，二级紧邻主标题或贴近同侧边缘。适合横版角色海报，是默认优先方案。

### 顶部标题

标题靠近上缘，人物从下方进入，保留明确头顶留白。适合竖版人物；一级可横排或短竖排，二级作为更小副行。

### 边缘竖排标题

短中文或准确日文沿左／右边缘竖排，人物采用极近景裁切；英文可旋转或纵向排列，但不能退化为机械 UI 标签。

### 情侣双标题

两个人名分别靠近各自人物，中心视线、接触点或近接触白色关系通道保持无字。二级作品名只出现一次，不在两侧重复；两个人名可以沿用双方角色主色。

### 动作轴标题

只用于明显跑跳、攻击或挥击。标题方向服从唯一动作轴，可被武器、手臂或外轮廓遮住少量笔画，但遮挡后仍可读；不得形成第二条相反文字方向。

用户明确要求“大标题、人物压住文字”时，允许标题位于人物后方并被发梢、肩部或外轮廓局部遮挡；这只是所选版式中的图文关系，不新增第二种版式。

## 5. 字体表现与颜色

一次只选一种组合：

- **同墨手写标题**：与人物主墨色一致，有轻微笔压与重写痕迹，但字形仍清楚；最接近参考语料。
- **清楚窄体标题**：适合英文作品名、官方代号或设定编号；字距克制，不做商业杂志式字体拼盘。
- **手写主标题＋规整小字**：一级手写、二级窄体，是默认推荐组合。

一级标题优先沿用人物主墨色，二级使用同色更浅或更细的层级。情侣双标题可分别沿用双方角色主色。不得为标题引入无关第三色；背景继续遵守中性纯白数字画布合同。

## 6. 观看顺序与保护区

- **人物优先（默认）**：先识别人物，再读一级标题，最后读可选二级。
- **图文平衡**：只有用户说“标题明显一点、角色宣传海报”等时启用；标题可以与人物接近同级。
- **标题优先**：只有用户明确说“大标题主视觉、字体主导”时启用。

无论哪种优先级，文字不得遮挡眼睛、鼻口、手指、角色身份锚点、指定接触点或近接触白色关系通道。标题占据的是构图预留的负空间，不是把完成的人物随意覆盖。

## 7. 提示词编译

标题系统激活后只增加两段紧凑信息：

```text
版式句：人物位置、标题位置、图文重量和必要遮挡关系。
文字句：一级准确文字、可选二级准确文字、语言、字体表现，以及只出现这些文字。
```

不要把五种候选版式、全部语言规则或完整验收清单塞进最终提示词。负面约束只增加当前必要的一组，例如“额外字符、伪日文、随机编号、签名或水印”。

示例：

```text
人物偏置在画面右侧约三分之二，左侧保留连续纯白负空间；一级标题“ASUKA”以同墨色手写英文置于左上区域，二级“EVANGELION”使用更小、更细的窄体字紧贴其下。人物身份优先，标题不遮挡眼睛和手势；画面只出现这两组准确文字，不添加随机编号、日期、签名、水印或伪字符。
```

## 8. 准确性与降级

- 普通生成适合短角色名、短标题、简短英文和官方代号；生成后检查文字内容、大小写、字符数量和额外字符。
- 首轮只有文字错误时，只修文字区域，不重新设计人物、动作、颜色和线场。
- 用户明确说“文字必须完全准确、可直接发布、不能错字”时，优先采用两阶段路径：先生成预留标题区的无字母稿，再用确定性排版加入准确文字并检查。
- 当前工具无法做确定性排版时，如实说明只能尝试模型内文字，不能声称已经保证准确。
- 长中文、长台词、复杂日文和多行小字不强塞进生图；缩短一级文字、删除二级或改走后期排版。

## 9. 失败判定

以下任一情况需要修正：

- 没有明确触发却出现角色名、日文或其他文字；
- 出现第三级信息、随机日期、时间、坐标或无依据编号；
- 标题语言违背用户指定，或把中文输入擅自改成日文／英文；
- 伪日文、乱码、错字、额外字符、签名、水印或账号；
- 标题遮住脸、手、身份锚点、接触点或关系通道；
- 标题色污染 #FFFFFF 背景，或加字触发黄白纸张、做旧和商业杂志风；
- 一张图同时使用多个竞争版式、三种书写系统或多套字体机制。
