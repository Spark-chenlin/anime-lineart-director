# v3.1.1 行为回归测试

只在维护、升级或系统测试 Skill 时读取。测试可观察决策和生成结果，不要求输出固定措辞。

## 使用方法

对每个案例检查：

1. 是否保留用户明确意图；
2. 是否只选择一个主笔触；
3. 构图、画布、配色和效果是否处在正确维度；
4. 是否守住参考风格边界；
5. 是否发生对应的禁止漂移；
6. 直接生图、提示词、诊断等输出动作是否正确。

## 已知故障专项

### 黄白背景

输入：“画一个简单的动漫男生，不要背景。”

通过条件：

- 明确使用视觉语法中的纯白数字画布视觉合同；
- “不要背景”被解释为无场景但仍有不透明纯白画布；
- 无纸色、纸纹、扫描颗粒、暗角或光照染色。
- 视觉中性的 252–255 近白不因数值浮动单独判为风格失败；只有用户明确要求技术纯白时才做背景归一化和逐像素检查。

### 彩铅／精致插画漂移

输入：“安静、青春、像恋爱动画里的男生。”

通过条件：

- 情绪只影响姿态、表情和线条节奏；
- 默认仍是参考范围内的受控单色圆珠笔式结构线与排线；
- 不自动加入肤色、夕阳、暖光、彩铅、水彩或完整背景。

### AI 毛线团

输入：“线稿更手写、更乱一点。”

通过条件：

- 不直接堆叠“更乱、更多 scribble”；
- 优先增加贴结构的纠正线、笔压差和方向性；
- 主轮廓、眼睛、手与接触点保持清楚；
- 不出现同半径线圈、等距波浪和跨物体缠绕。

### 双人唯一接触

输入：“两人额头轻触，其他地方不要碰。”

通过条件：

- 同时描述允许接触部位、允许接触材质和非接触留缝；
- 指定裸露部位必须形成明确、连续、没有可见白缝的真实相切节点；
- 头发从接触节点退让；
- 鼻尖、嘴唇、手和衣物没有新增接触。

### 单一动作轴

输入：“少年挥刀冲向镜头，要有速度。”

通过条件：

- 明确轴线起点、经过的肩肘手腕或其他受力关节，以及刀尖／拳头等终点；
- 主要速度线与轴线平行、向终点汇聚或顺轴延伸；
- 轴线两侧存在低密度空白通道；
- 不出现第二组主轴、四周径向爆线或包围主体的爆炸中心。

### 角色主色双墨

输入：“画两个具名动漫角色的情侣或关系图，自动配色。”

通过条件：

- 用户指定颜色优先；
- 否则每个人物从可靠身份信息中选择一个主要识别色作为完整个人线场；
- 冷蓝／暖橙只在角色主色不明确时作为后备方案；
- 两套颜色不混成第三色，不扩散成完整彩虹上色。

### 像素级纯白

输入：“背景文件必须每个像素严格为 #FFFFFF。”

通过条件：

- 生成提示词仍要求视觉中性纯白；
- 明确说明提示词本身不能保证逐像素数值；
- 生成后执行确定性背景归一化并检查像素，或在无法执行时如实说明未满足技术合同。

## 验收

升级至少满足：

- E01–E19 的导演决策全部通过；其中 E03、E18、E19 分别覆盖明确唯一接触、自然亲密接触和近接触张力；
- 七个专项都能指出明确、可观察的通过条件；
- 不依赖特定标题、固定段落数量或正则措辞；
- 没有为了单个案例增加会伤害其他任务的通用绝对规则。
