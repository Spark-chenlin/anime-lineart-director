# v3 行为回归测试

只在维护、升级或系统测试 Skill 时读取。测试可观察决策和生成结果，不要求输出固定措辞。

## 使用方法

对每个案例检查：

1. 是否保留用户明确意图；
2. 是否只选择一个主笔触；
3. 构图、画布、配色和效果是否处在正确维度；
4. 是否守住参考风格边界；
5. 是否发生对应的禁止漂移；
6. 直接生图、提示词、诊断等输出动作是否正确。

## 核心案例

| 编号 | 输入 | 必须出现的行为 | 禁止漂移 |
|---|---|---|---|
| E01 默认男性 | “画一个冷淡短发动漫男生。” | 定向圆珠笔、皇家蓝单色、纯白数字画布、无文字 | 彩铅、暖纸、完整场景、角色姓名 |
| E02 温柔女性 | “画一个安静温柔的长发女孩。” | 情绪改变表情和线条节奏；可选轨道纠正线 | 因“温柔”触发暖黄纸、水彩、柔焦 |
| E03 情侣接触 | “画一对害羞情侣，只有额头接触。” | 两套个人线场、裸露额头材质白名单、鼻唇留缝 | 刘海接触、脸部融合、共享毛线团 |
| E04 动作少年 | “少年挥刀冲向镜头，要有速度。” | 尖锐动作线、唯一动作轴、脸手保护区 | 四周均匀爆炸、圆环主导、动作不可读 |
| E05 高密长发 | “黑长发几乎压成一片，但脸要干净。” | 发型内 D3–D4、白缝切开、脸部 D0–D1 | 密线铺进皮肤、均匀网格 |
| E06 压迫哭泣 | “女孩抬手遮脸哭泣，压迫感。” | 马克笔暗块＋白刮痕，先锁定眼睛和手势 | 暗块覆盖五官、散景或纸纹自动加入 |
| E07 明确完整上色 | “保持这种乱线，但角色要完整彩色。” | 明确彩色授权，仍保留 L0–L2 和排线 | 光滑赛璐璐、线稿消失 |
| E08 黑底反相 | “同一角色做黑底发光版本。” | 沿用母稿主笔触，黑底作为画布策略，有限辉光 | 把黑底当新笔触、赛博城市、金属 3D |
| E09 禁止文字 | “做一张人物靠右的横海报。” | 左侧保持纯白负空间 | 自动标题、角色名、伪日文、签名 |
| E10 指定文字 | “左边写‘夏日未完’，不要别的字。” | 只出现准确文案并规定位置权重 | 多余字符、署名、水印 |
| E11 系列一致性 | “同一角色做横、竖、方三版。” | 固定身份、动作、主笔触和密度地图；逐版只改构图 | 每版换服装、动作、颜色和风格 |
| E12 只要提示词 | “给我一个这种风格的女生提示词。” | 输出方案、完整提示词、必要负面约束 | 未经要求直接生图、展开参数教程 |
| E13 直接生图 | “画五条悟，酷一点，直接出图。” | 内部自动导演并调用图像生成能力 | 停下来要求填写选项表 |
| E14 返图诊断 | “这张图为什么不像参考风格？” | 依据可见证据指出一个主要偏差和优先修正 | 未经要求直接重做或臆测原始 prompt |

## 已知故障专项

### 黄白背景

输入：“画一个简单的动漫男生，不要背景。”

通过条件：

- 明确使用视觉语法中的 #FFFFFF 数字画布合同；
- “不要背景”被解释为无场景但仍有不透明纯白画布；
- 无纸色、纸纹、扫描颗粒、暗角或光照染色。

### 彩铅／精致插画漂移

输入：“安静、青春、像恋爱动画里的男生。”

通过条件：

- 情绪只影响姿态、表情和线条节奏；
- 默认仍是皇家蓝圆珠笔式结构线与排线；
- 不自动加入肤色、夕阳、暖光、彩铅、水彩或完整背景。

### AI 毛线团

输入：“线稿更手写、更乱一点。”

通过条件：

- 不直接堆叠“更乱、更多 scribble”；
- 优先增加贴结构的纠正线、笔压差和方向性；
- 主轮廓、眼睛、手与接触点保持清楚；
- 不出现同半径线圈、等距波浪和跨物体缠绕。

### 双人唯一接触

输入：“两人额头轻触，其他地方不要碰。”

通过条件：

- 同时描述允许接触部位、允许接触材质和非接触留缝；
- 头发从接触节点退让；
- 鼻尖、嘴唇、手和衣物没有新增接触。

## 验收

升级至少满足：

- E01–E14 的导演决策全部通过；
- 四个专项都能指出明确、可观察的通过条件；
- 不依赖特定标题、固定段落数量或正则措辞；
- 没有为了单个案例增加会伤害其他任务的通用绝对规则。
