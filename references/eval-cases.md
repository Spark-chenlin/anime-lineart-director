# v3.2.1 行为回归测试

只在维护、升级或系统测试 Skill 时读取。测试可观察决策和生成结果，不要求输出固定措辞。

## 使用方法

对每个案例检查：

1. 是否保留用户明确意图；
2. 是否只选择一个主笔触；
3. 构图、画布、配色和效果是否处在正确维度；
4. 是否守住参考风格边界；
5. 是否发生对应的禁止漂移；
6. 直接生图、提示词、诊断等输出动作是否正确。

## 核心案例

| 编号 | 输入 | 必须出现的行为 | 禁止漂移 |
|---|---|---|---|
| E01 默认男性 | “画一个冷淡短发动漫男生。” | 定向圆珠笔、参考内受控单色、视觉纯白数字画布、无文字 | 所有默认图机械锁死皇家蓝、彩铅、暖纸、完整场景、角色姓名 |
| E02 温柔女性 | “画一个安静温柔的长发女孩。” | 情绪改变表情和线条节奏；可选轨道纠正线 | 因“温柔”触发暖黄纸、水彩、柔焦 |
| E03 情侣接触 | “画一对害羞情侣，只有额头接触。” | 进入精确模式；用一个允许触点和一个主要分离区表达，负面约束保持短小 | 额头仍有空隙、脸部融合、把全部微几何诊断复制进提示词 |
| E04 动作少年 | “少年挥刀冲向镜头，要有速度。” | 尖锐动作线；轴线起点、受力关节、终点和空白通道明确 | 四周均匀爆炸、第二组射线、圆环主导、动作不可读 |
| E05 高密长发 | “黑长发几乎压成一片，但脸要干净。” | 发型内 D3–D4、白缝切开、脸部 D0–D1 | 密线铺进皮肤、均匀网格 |
| E06 压迫哭泣 | “女孩抬手遮脸哭泣，压迫感。” | 马克笔暗块＋白刮痕，先锁定眼睛和手势 | 暗块覆盖五官、散景或纸纹自动加入 |
| E07 明确完整上色 | “保持这种乱线，但角色要完整彩色。” | 明确彩色授权，仍保留 L0–L2 和排线 | 光滑赛璐璐、线稿消失 |
| E08 黑底反相 | “同一角色做黑底发光版本。” | 沿用母稿主笔触，黑底作为画布策略，有限辉光 | 把黑底当新笔触、赛博城市、金属 3D |
| E09 禁止文字 | “做一张人物靠右的横海报。” | 左侧保持纯白负空间 | 自动标题、角色名、伪日文、签名 |
| E10 指定文字 | “左边写‘夏日未完’，不要别的字。” | 只出现准确文案并规定位置权重 | 多余字符、署名、水印 |
| E11 系列一致性 | “同一角色做横、竖、方三版。” | 固定身份、动作、主笔触和密度地图；逐版只改构图 | 每版换服装、动作、颜色和风格 |
| E12 只要提示词 | “给我一个这种风格的女生提示词。” | 输出方案、完整提示词、必要负面约束 | 未经要求直接生图、展开参数教程 |
| E13 直接生图 | “画五条悟，酷一点，直接出图。” | 内部自动导演并调用图像生成能力 | 停下来要求填写选项表 |
| E14 返图诊断 | “这张图为什么不像参考风格？” | 依据可见证据指出一个主要偏差和优先修正 | 未经要求直接重做或臆测原始 prompt |
| E15 角色主色情侣 | “画炭治郎和香奈乎的双人关系图，自动配色。” | 分别从两名角色可靠主色建立个人线场 | 机械套用冷蓝／暖橙、完整赛璐璐上色 |
| E16 原创情侣配色 | “画一对原创恋爱动漫情侣，没有指定颜色。” | 根据角色设计选择单色、相邻色或克制后备双色 | 把冷蓝／暖橙当唯一答案、随机彩虹 |
| E17 连续默认颜色 | 连续生成男性、女性、情侣、动作人物和海报 | 在参考内墨色和点色中出现受控变化 | 五张全部机械皇家蓝、为求变化漂成彩铅或黄纸 |
| E18 自然亲密接触 | “画一对近距离对视的情侣，头顶和刘海轻触，女生拉住男生衣领。” | 头发相切与手指—衣领形成两个清楚关系节点，鼻唇留窄白缝，不强制露额 | 因额头未露而判失败、删除衣领接触、脸部融合、鼻唇误接触 |
| E19 近接触张力 | “画一对即将接吻的情侣，脸很近但不要碰到。” | 鼻尖和嘴唇之间保留连续狭窄的纯白负空间，以姿态和视线表达张力 | 强行补成额头或鼻唇接触、距离过远、共享线团填满脸间留白 |
| E20 普通静态动作 | “男生靠在栏杆边，一只手插兜。” | 只写支撑位置、身体方向和手部任务 | 强行展开肩肘腕全关节轴线、加入速度线 |
| E21 搜索线与无接触 | “两人脸靠得很近，但任何地方都不要碰。” | 两人之间形成连续白色关系通道，辅助寻找线在通道外终止 | 一边要求自由越界线，一边逐项禁止所有身体部位造成冲突 |
| E22 模糊亲密关系 | “画一对很亲密的情侣对视。” | 选择一个自然关系机制，以姿态和视线优先，不固定露额或节点数量 | 同时列出额头、刘海、头顶、肩部、衣领等全部候选触点 |
| E23 提示词压缩 | 任一普通单人或双人提示词 | 一个主成立点、一个动作／关系机制、一个主笔触机制、2–4 组负面漂移 | 把导演闸门、L0–L4、D0–D4 和完整验收清单逐项输出 |

## 配色专项

| 编号 | 输入 | 必须出现的行为 | 禁止漂移 |
|---|---|---|---|
| P01 人物主色默认 | “画明日香，没有指定颜色。” | 把有把握的暖红／橙红身份色转译为受控主墨线 | 随机蓝色、恢复完整肤色与战斗服赛璐璐上色 |
| P02 黑色墨线 | “画一个黑色圆珠笔线稿男生，白底。” | 黑／炭黑／石墨灰墨线仍使用 #FFFFFF 画布 | 误路由为黑底反相、灰色纸张或铅笔素描 |
| P03 红色动作线 | “红色线稿少年挥刀冲过来。” | 红色作为尖锐动作墨线，速度线服从唯一动作轴 | 红色铺满人物、火焰场景或第二主轴 |
| P04 青蓝色域 | “画一个青蓝色线稿少女。” | 使用青蓝／蓝绿色受控墨线并保持纯白背景 | 自动退回皇家蓝、背景被染成青色 |

## 已知故障专项

### 黄白背景

输入：“画一个简单的动漫男生，不要背景。”

通过条件：

- 明确使用视觉语法中的纯白数字画布视觉合同；
- “不要背景”被解释为无场景但仍有不透明纯白画布；
- 无纸色、纸纹、扫描颗粒、暗角或光照染色。
- 视觉中性的 252–255 近白不因数值浮动单独判为风格失败；只有用户明确要求技术纯白时才做背景归一化和逐像素检查。

### 彩铅／精致插画漂移

输入：“安静、青春、像恋爱动画里的男生。”

通过条件：

- 情绪只影响姿态、表情和线条节奏；
- 默认仍是参考范围内的受控单色圆珠笔式结构线与排线；
- 不自动加入肤色、夕阳、暖光、彩铅、水彩或完整背景。

### AI 毛线团

输入：“线稿更手写、更乱一点。”

通过条件：

- 不直接堆叠“更乱、更多 scribble”；
- 优先增加贴结构的纠正线、笔压差和方向性；
- 主轮廓、眼睛、手与接触点保持清楚；
- 不出现同半径线圈、等距波浪和跨物体缠绕。

### 双人唯一接触

输入：“两人额头轻触，其他地方不要碰。”

通过条件：

- 进入高难度精确接触模式，但不把它当普通情侣默认；
- 正向描述一个允许触点和一个主要分离区；
- 提示词不穷举刘海、发际线、发饰、每根发丝和全部身体部位；
- 返图后只针对实际失败追加一条局部修复。

### 单一动作轴

输入：“少年挥刀冲向镜头，要有速度。”

通过条件：

- 明确轴线起点、经过的肩肘手腕或其他受力关节，以及刀尖／拳头等终点；
- 主要速度线与轴线平行、向终点汇聚或顺轴延伸；
- 轴线两侧存在低密度空白通道；
- 不出现第二组主轴、四周径向爆线或包围主体的爆炸中心。

### 角色主色双墨

输入：“画两个具名动漫角色的情侣或关系图，自动配色。”

通过条件：

- 用户指定颜色优先；
- 否则每个人物从可靠身份信息中选择一个主要识别色作为完整个人线场；
- 冷蓝／暖橙只在角色主色不明确时作为后备方案；
- 两套颜色不混成第三色，不扩散成完整彩虹上色。

### 像素级纯白

输入：“背景文件必须每个像素严格为 #FFFFFF。”

通过条件：

- 生成提示词仍要求视觉中性纯白；
- 明确说明提示词本身不能保证逐像素数值；
- 生成后执行确定性背景归一化并检查像素，或在无法执行时如实说明未满足技术合同。

### 配色策略打架

输入：“按参考风格自动配色。”

通过条件：

- 先选择一种主配色策略，再从参考内色域选择色相；
- 具名角色优先把可靠主色转译为墨线，原创角色才从参考内色域自动选择；
- 普通单图不同时叠加双墨、渐变、局部平涂、完整彩色和黑底反相；
- 黑色墨线保持白底，渐变与点色不污染 #FFFFFF 背景。

## 验收

升级至少满足：

- E01–E23 的导演决策全部通过；其中 E03、E18、E19 分别覆盖明确唯一接触、自然亲密接触和近接触张力，E20–E23 覆盖动作骨架、线条冲突与编译压缩；
- P01–P10 的配色决策全部通过，尤其守住人物主色优先、黑线白底、参考内色域、授权渐变／平涂和系列单变量；
- 八个专项都能指出明确、可观察的通过条件；
- 不依赖特定标题、固定段落数量或正则措辞；
- 没有为了单个案例增加会伤害其他任务的通用绝对规则。
