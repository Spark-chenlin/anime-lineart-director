# 自动导演工作流

本文件负责把用户需求转换成风格内决策。视觉事实以 [视觉语法](visual-grammar.md) 为准；需要模式细节或示例时再读 [模式与示例](modes-and-examples.md)；用户明确触发文字时读取 [双层标题海报系统](title-poster.md)。

## 1. 先判断任务

按用户真正要的交付路由：

- **提示词**：输出完整中文提示词和当前必要的负面约束。
- **直接生图**：内部编译提示词后调用可用的图像生成能力。
- **系列／多版**：先固定母稿，再生成或描述 2–4 个单变量版本。
- **方向比较**：给最多三个口语化方向，说明画面差异。
- **帮助／介绍**：解释一句话用法、能力范围和可选方向。
- **返图诊断**：只根据可见结果判断最主要偏差，不擅自修改。
- **风格反推**：描述可见视觉机制，再给重建提示词；不声称恢复原始 prompt。

如果用户同时提出内容和“直接出图”，不要停在提示词交付。

## 2. 锁定用户意图

生成前在内部形成一份最小意图锁：

| 维度 | 优先级 | 缺省处理 |
|---|---:|---|
| 角色／身份锚点 | 最高 | 未指定则用原创动漫人物；具名角色选 2–4 个可靠辨识锚点 |
| 人数与关系 | 最高 | 单人 |
| 动作、表情、视线 | 高 | 与语义一致的克制姿态 |
| 接触、遮挡、手部归属 | 高 | 根据措辞选择明确接触、自然亲密接触或近接触张力；不擅自增加复杂接触 |
| 服装与道具 | 高 | 简洁、符合角色锚点 |
| 画幅、景别、裁切 | 中 | 头像或半身，按动作调整 |
| 主墨色与强调色 | 中 | 可靠角色主色或参考内受控单色；信息不足才回退皇家蓝 |
| 底色／材质 | 高 | 使用视觉语法中的白底合同 |
| 文字 | 高 | 默认无文字；普通“海报”不等于标题海报 |
| 输出动作 | 最高 | 按用户原话执行 |

用户明确指定的值不可被自动路由覆盖。未知内容只做最小补全，不为了“更有画面”擅自添加场景、道具、剧情、天气、纸张或光效。

## 3. 决定是否询问

默认不询问。满足以下全部条件才问一个最短问题：

1. 缺失信息会明显改变身份、人物关系或核心动作；
2. 两种解释无法同时成立；
3. 从上下文不能合理推断；
4. 任取其一会显著偏离用户意图。

风格、颜色、构图和密度通常由 Skill 自动决定。用户主动要选择时，最多给三个结果导向的口语化方向，不显示内部层级代码。

## 4. 选择配置

先写出一句内部主成立点，例如“角色身份先成立”“挥刀冲势先成立”或“亲密但未接触的张力先成立”。一张图只能有一个主成立点；风格线层、构图、颜色和附加效果都为它服务。

严格使用：

```text
1 个主成立点
+ 1 个主笔触
+ 1 个构图策略
+ 1 个画布/配色策略
+ 0–1 个附加效果
+ 0–1 个标题版式层
```

### 主笔触

- 普通、清楚、克制、未指定：定向圆珠笔排线。
- 长发流动、回望、明显作画寻找感：轨道弧线／纠正线。
- 深色长发、局部接近实色：高密发丝场。
- 战斗、速度、攻击性：尖锐动作线。
- 哭泣、惊惧、压迫和强黑白：马克笔暗块＋白刮痕。

情绪不能单独触发外部媒介。比如“温柔”不触发彩铅，“怀旧”不触发黄纸，“酷”不触发 3D 霓虹。

### 构图

根据人物关系和动作选择头像、半身、动作方图、人物偏置海报、双人近景、双联画或同母稿横竖方变体。构图不是笔触模式。

双人近景只选择一种关系机制：明确部位接触、自然亲密或近接触张力。普通“靠近、依偎、亲密对视”以姿态、视线和自然关系节点成立，不在提示词里穷举额头、头顶、刘海、肩部、衣领等所有候选方案。只有用户明确说“只有、仅、其他地方不要碰”时，才进入精确接触模式。

### 画布与配色

按以下优先级选择，不把“未指定颜色”直接等同于皇家蓝：

1. 用户明确颜色；
2. 具名角色可靠的主要识别色；
3. 原创角色由发色、服装大色块和主题推导的一种参考内墨色；
4. 信息仍不足时回退皇家蓝。

单人通常使用一种主墨色和最多一个身份点色。情侣优先分别使用两名角色自身的主要识别色；只有角色主色不明确且关系构图确实需要颜色区分时，才使用克制冷暖双色。多人优先共享主墨色并以少量点色区分，禁止随机彩虹分配。完整彩色、黑底反相、实体纸张、暖色底和明显渐变仍必须由用户明确触发。白底以视觉中性 #FFFFFF 为目标。

### 附加效果

默认不用。只有用户明确要求，或效果对动作／关系不可替代时，才选择一种喷溅、半调、错色副线、白刮痕、有限辉光或外围关系弧线。

### 标题版式层

默认关闭。“带名字、标题海报、加作品名、双标题、档案版、字体主视觉”或用户提供必现文字时才打开；普通人物偏置海报仍保持无字留白。

打开后按以下顺序决定：

1. **文字来源**：用户逐字文案优先；只有“带名字的海报版”时，沿用用户输入中的角色名作为一级标题。
2. **两级层级**：一级为角色名／主标题；二级只选择作品名、官方代号或设定编号中的一种，没有可靠内容则省略。
3. **语言**：用户指定优先；否则沿用输入语言；只有用户要求按作品自动选择时才采用有把握的官方形式。
4. **版式**：侧边留白、顶部、边缘竖排、情侣双标题、动作轴标题五选一。
5. **题字构造**：一级先选择一个与构图一致的整组书写动势，再构造非矩形外轮廓、非统一字框的准确字符骨架；二级使用更小、更细的手工窄字。只有用户明确要求规整字体时才关闭该默认。
6. **观看顺序**：默认人物优先；用户明确要求时才提升为图文平衡或标题优先。
7. **生成与准确性路径**：只要提示词时编译完整题字构造；直接生图且可局部编辑时，默认无字母稿＋题字区域生成。用户要求完全准确时改走可验证的确定性后期排版，且不得退化为与人物割裂的系统字体。

不要在生成前强制让用户选择语言或版式。只有标题模式已触发却没有可用的一级文字，或文字内容存在多种解释且任取其一会明显偏离意图时，才问一个最短问题。

## 5. 生图前导演闸门与冲突检查

编译前逐项确认：

1. 用户明确的角色、关系、动作、构图、颜色、背景、文字和输出动作是否全部保留？
2. 是否只有一个主笔触？
3. 黑底、双联、点色和效果是否被放在正确维度？
4. 是否存在未经用户授权的纸张、彩铅、水彩、柔焦、散景、辉光、完整场景或文字？
5. L0 能否先独立表达人物身份、动作和关系？
6. 脸、手和接触点是否有保护区？
7. 双人是否有两套个人线场、明确遮挡，并按用户措辞选对了明确接触、自然亲密接触或近接触张力？
8. 具名角色是否使用可靠身份锚点和主要识别色，而非机械套用皇家蓝或冷蓝／暖橙？
9. 普通姿态是否只写动作骨架；明显跑跳、攻击或挥击才展开主轴起点、受力关节、终点和空白通道？
10. 是否只选择一个关系机制；用户要求接触时该动作是否可见，要求不接触时两个人物间是否有连续白色关系通道，未要求“只有”时是否避免擅自施加唯一接触限制？
11. 默认背景是否套用视觉白底合同；若用户要求逐像素 #FFFFFF，是否已计划确定性后处理而非只依赖提示词？
12. 文字是否确由用户触发；是否只有一个标题版式和最多两级准确内容，语言路由正确且不遮挡人物／关系保护区；一级题字是否具有一个整组动势、非矩形外轮廓和非统一字符骨架，而不是规整字体块加毛边？

再检查以下高频冲突：

| 冲突 | 解决方式 |
|---|---|
| 手写寻找线 vs 脸、手、接触或无接触通道 | 保留手写感，但让辅助线在保护区外减弱或终止 |
| 高密发丝 vs 清楚接触节点 | 接触节点优先，高密度退到发根和外侧暗部 |
| 自然亲密 vs 精确唯一触点 | 没有排他措辞时使用自然亲密，不启用精确模式 |
| 近距离构图 vs 完全不接触 | 用连续白色关系通道表达，不逐项枚举所有身体部位 |
| 角色主色双墨 vs 接触处不得混色 | 先保证双方身份可读，触点低纹理；不要求像素级分色边界 |
| 动作自然度 vs 全关节几何 | 普通动作只留支撑、方向和手部任务；高速动作才展开轴线 |
| 标题海报 vs 默认无文字 | 只有明确文字触发才加标题；普通海报继续保留无字留白 |
| 作品适配语言 vs 伪日文／误译 | 默认沿用用户输入；只有明确授权才自动选择可靠官方形式 |
| 大标题 vs 人物身份／关系焦点 | 默认人物优先；标题退到预留负空间并避开脸、手、触点和关系通道 |
| 双层标题 vs 信息堆积 | 一级只放角色名／主标题，二级三选一，删除日期、时间、坐标和随机小字 |
| 文字准确 vs 题字自然 | 短标题用无字母稿隔离人物，再生成题字区域并按骨架验收；必须完全准确时走确定性排版，但后期仍须匹配人物线色与题字轮廓，不直接接受系统字库感 |
| 单标题自由度 vs 不得虚构二级 | 不补作品名或编号；用一级自身的起笔拖线、收笔越界或未闭合题字轨迹建立视觉锚点 |

发现冲突时，以“用户明确意图 → 主成立点 → 人物结构与关系 → 风格效果”的顺序取舍。任何一项失败，先修内部配置，不进入提示词编译或生图。

## 6. 提示词编译与压缩

内部可以完整检查所有模块，最终只编译本图实际选中的内容。写成一个连续中文自然语言段落，按五段逻辑压成一条执行链：

```text
主体与构图
→ 一个动作骨架或关系机制
→ 一个主笔触及其结构性线行为
→ 配色与画布
→ 可选标题版式与准确文字
→ 当前最相关的少量防错
```

编译规则：

- 每张图只写一个主成立点、一个动作／关系机制和一个主笔触机制；未选中的候选动作、接触位置、线层和效果不进入提示词。
- 普通动作使用“支撑／依靠位置 + 整体方向 + 手部任务”的骨架；只有高速动作才写轴线起点、关键受力位置和终点。
- 关系描述优先写正向结果。自然亲密写“如何亲密且仍可分辨”，近而不触写“连续白色关系通道”，精确接触只写一个允许触点和一个主要分离区。
- L0–L4、D0–D4 和质量闸门只用于内部推理；最终转写成一到两句可观察的线条与密度行为。
- 同一概念通常只出现一次；确有高风险时可在负面约束中再出现一次，不用同义词连续重复。
- 没有使用的线层、效果、文字和修复规则不要硬塞。过去案例的验收细节不得自动变成新图的通用要求。
- 标题模式只增加一条版式句和一条文字句：前者写人物／标题位置与重量，后者写一级、可选二级、语言、整组书写动势、字符骨架差异和“只出现这些文字”；不展开未选中的候选版式。

### 负面约束

负面约束只保留当前画面最可能发生的 2–4 组漂移。优先选择：结构性乱线、当前关系／动作错误、当前媒介漂移、当前画布漂移。不要默认复制完整通用清单。

例如普通白底人物可使用：

```text
无结构归属的随机线团；五官和手部被密线遮挡；普通精修线稿或完整赛璐璐上色；黄白纸张、纸纹和未经授权文字。
```

双人图把其中一组替换为当前最可能的关系错误；动作图替换为第二主轴或四周爆线；黑底图替换为 3D 霓虹和宽辉光。不要禁止当前模式必需的长弧、暗块、点色或平涂。

标题模式把“未经授权文字”替换为最相关的一组，例如“额外字符、伪日文、随机编号、签名或水印”，或在题字违和风险更高时使用“规整字体块、统一字框与完美基线、毛边伪装标准骨架”；不重复列出完整文字合同。

### 编译后压缩闸门

交付前再问：

1. 删除任一句后，画面机制是否完全不变？若是，删除。
2. 是否出现了未被选中的动作、接触候选或附加效果？若是，删除。
3. 是否用三个以上近义否定词描述同一个失败？若是，只留最直接的一条。
4. 是否把诊断或验收步骤写成了模型必须逐项执行的长清单？若是，改回一个正向画面结果。

## 7. 输出动作

- 用户只要提示词：交付风格方案、完整提示词、负面约束；不要附教程。
- 用户明确要生图：使用编译后的完整提示词直接生成，以图片为主要结果；标题模式且工具支持局部编辑时，自动先生成无字母稿，再只处理题字区域，不把选择题交给用户。
- 用户要多版：先固定人物、动作、L0 结构和密度地图，每版只改变构图、配色、底色或效果中的一个变量。
- 用户要诊断：先指出一个主要失败及其可见证据；用户要求修复后再重写或生图。

## 8. 生图后质量闸门

按优先级检查：

1. **身份与关系**：人物是否可识别，动作、视线、遮挡、手和接触是否正确。
2. **主轮廓**：脸、五官、发型大形和手势是否能脱离乱线独立读出。
3. **线条归属**：密线是否跟随发束、衣褶、投影或动作轴。
4. **手写自然度**：是否有不规则停顿、重描和笔压差，而非机械卷曲。
5. **密度层级**：是否有低、中、高区，脸手是否仍为焦点。
6. **风格边界**：是否漂成彩铅、水彩、普通精修动漫、厚涂或 3D。
7. **动作与接触**：动作图是否只有一个优势轴；明确接触是否真的相切，自然亲密接触是否清楚而不融合，近接触是否保留用户要求的窄白负空间。
8. **颜色身份**：具名角色的主墨色是否来自可靠角色主色；情侣是否避免机械冷蓝／暖橙。
9. **画布与文字**：白底是否视觉中性、均匀且不透明，是否出现纸纹、可见色偏或未经授权文字；只有用户要求技术纯白时才检查逐像素 #FFFFFF。
10. **标题系统（若启用）**：一级和可选二级是否准确，语言是否符合路由，是否只有一个版式且不遮挡人物与关系保护区；忽略毛边和排线后，一级是否仍具有非矩形整组轮廓、明显不同的字符占宽／重心／基线与非复制重复部件；若仍像规整字体块则失败。要求完全准确时是否采用可验证且视觉相容的确定性排版路径。

## 9. 单变量修正

每轮只修最主要的一项：

| 失败 | 首要修正 |
|---|---|
| 人物或关系不成立 | 修 L0、姿态、遮挡和接触，不先加线 |
| 像 AI 毛线团 | 删除无归属线，重新分配 L1/L2/L3 方向和权重 |
| 太像普通干净线稿 | 增加贴结构的 L2 偏移与笔压差，不增加随机线 |
| 五官或手被覆盖 | 恢复 D0 保护区，降低穿越线权重 |
| 全画面同密度 | 把高密限制到发根、暗面或动作边缘 |
| 动作线四周放射 | 固定主轴起点和终点，删除其他方向射线，只保留平行、汇聚或顺轴延伸的线 |
| 明确要求接触但仍有空隙 | 只移动相关部位，直到用户指定的部位与材质形成真实相切；只有用户明确要求“只有”时才删除其他接触节点 |
| 普通亲密构图被强制露额 | 恢复符合语义的头顶／刘海／发际轻触或手与衣物接触，不把裸露额头当通用模板 |
| 即将接吻却意外接触 | 重新打开鼻尖与嘴唇之间连续、狭窄的纯白负空间，保留靠近姿态与视线张力 |
| 情侣颜色机械蓝橙 | 恢复两名角色各自可靠主色；只有主色不明时才使用关系后备配色 |
| 情绪图漂成彩铅／暖纸 | 恢复默认墨线与白底合同，不改变表情和姿态 |
| 白底黄白或有纸纹 | 只修视觉画布合同，删除实体纸张和光照染色词；像素级纯白需求另走确定性后处理 |
