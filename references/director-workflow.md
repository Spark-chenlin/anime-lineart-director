# 自动导演工作流

本文件负责把用户需求转换成风格内决策。视觉事实以 [视觉语法](visual-grammar.md) 为准；需要模式细节或示例时再读 [模式与示例](modes-and-examples.md)。

## 1. 先判断任务

按用户真正要的交付路由：

- **提示词**：输出完整中文提示词和当前必要的负面约束。
- **直接生图**：内部编译提示词后调用可用的图像生成能力。
- **系列／多版**：先固定母稿，再生成或描述 2–4 个单变量版本。
- **方向比较**：给最多三个口语化方向，说明画面差异。
- **帮助／介绍**：解释一句话用法、能力范围和可选方向。
- **返图诊断**：只根据可见结果判断最主要偏差，不擅自修改。
- **风格反推**：描述可见视觉机制，再给重建提示词；不声称恢复原始 prompt。

如果用户同时提出内容和“直接出图”，不要停在提示词交付。

## 2. 锁定用户意图

生成前在内部形成一份最小意图锁：

| 维度 | 优先级 | 缺省处理 |
|---|---:|---|
| 角色／身份锚点 | 最高 | 未指定则用原创动漫人物；具名角色选 2–4 个可靠辨识锚点 |
| 人数与关系 | 最高 | 单人 |
| 动作、表情、视线 | 高 | 与语义一致的克制姿态 |
| 接触、遮挡、手部归属 | 高 | 根据措辞选择明确接触、自然亲密接触或近接触张力；不擅自增加复杂接触 |
| 服装与道具 | 高 | 简洁、符合角色锚点 |
| 画幅、景别、裁切 | 中 | 头像或半身，按动作调整 |
| 主墨色与强调色 | 中 | 可靠角色主色或参考内受控单色；信息不足才回退皇家蓝 |
| 底色／材质 | 高 | 使用视觉语法中的白底合同 |
| 文字 | 高 | 默认无文字 |
| 输出动作 | 最高 | 按用户原话执行 |

用户明确指定的值不可被自动路由覆盖。未知内容只做最小补全，不为了“更有画面”擅自添加场景、道具、剧情、天气、纸张或光效。

## 3. 决定是否询问

默认不询问。满足以下全部条件才问一个最短问题：

1. 缺失信息会明显改变身份、人物关系或核心动作；
2. 两种解释无法同时成立；
3. 从上下文不能合理推断；
4. 任取其一会显著偏离用户意图。

风格、颜色、构图和密度通常由 Skill 自动决定。用户主动要选择时，最多给三个结果导向的口语化方向，不显示内部层级代码。

## 4. 选择配置

严格使用：

```text
1 个主笔触
+ 1 个构图策略
+ 1 个画布/配色策略
+ 0–1 个附加效果
```

### 主笔触

- 普通、清楚、克制、未指定：定向圆珠笔排线。
- 长发流动、回望、明显作画寻找感：轨道弧线／纠正线。
- 深色长发、局部接近实色：高密发丝场。
- 战斗、速度、攻击性：尖锐动作线。
- 哭泣、惊惧、压迫和强黑白：马克笔暗块＋白刮痕。

情绪不能单独触发外部媒介。比如“温柔”不触发彩铅，“怀旧”不触发黄纸，“酷”不触发 3D 霓虹。

### 构图

根据人物关系和动作选择头像、半身、动作方图、人物偏置海报、双人近景、双联画或同母稿横竖方变体。构图不是笔触模式。

双人近景先判断关系机制：明确“某部位相贴”就完成该部位与材质的真实相切；普通“靠近、依偎、亲密对视”可使用头发／头顶轻触和手与衣物接触等一到两个克制节点；“即将接吻、不要碰”则保留鼻唇之间的窄白负空间。只有用户明确说“只有、仅、其他地方不要碰”时，才启用唯一接触限制。

### 画布与配色

按以下优先级选择，不把“未指定颜色”直接等同于皇家蓝：

1. 用户明确颜色；
2. 具名角色可靠的主要识别色；
3. 原创角色由发色、服装大色块和主题推导的一种参考内墨色；
4. 信息仍不足时回退皇家蓝。

单人通常使用一种主墨色和最多一个身份点色。情侣优先分别使用两名角色自身的主要识别色；只有角色主色不明确且关系构图确实需要颜色区分时，才使用克制冷暖双色。多人优先共享主墨色并以少量点色区分，禁止随机彩虹分配。完整彩色、黑底反相、实体纸张、暖色底和明显渐变仍必须由用户明确触发。白底以视觉中性 #FFFFFF 为目标。

### 附加效果

默认不用。只有用户明确要求，或效果对动作／关系不可替代时，才选择一种喷溅、半调、错色副线、白刮痕、有限辉光或外围关系弧线。

## 5. 生图前导演闸门

编译前逐项确认：

1. 用户明确的角色、关系、动作、构图、颜色、背景、文字和输出动作是否全部保留？
2. 是否只有一个主笔触？
3. 黑底、双联、点色和效果是否被放在正确维度？
4. 是否存在未经用户授权的纸张、彩铅、水彩、柔焦、散景、辉光、完整场景或文字？
5. L0 能否先独立表达人物身份、动作和关系？
6. 脸、手和接触点是否有保护区？
7. 双人是否有两套个人线场、明确遮挡，并按用户措辞选对了明确接触、自然亲密接触或近接触张力？
8. 具名角色是否使用可靠身份锚点和主要识别色，而非机械套用皇家蓝或冷蓝／暖橙？
9. 动作图是否明确了主轴起点、经过的受力关节、终点和轴线两侧的空白通道？
10. 用户明确要求某部位接触时，该部位与材质是否形成没有可见白缝的真实相切节点；用户要求近而不触时，鼻唇之间是否保留窄白负空间；用户没有要求“只有”时，是否避免擅自施加唯一接触限制？
11. 默认背景是否套用视觉白底合同；若用户要求逐像素 #FFFFFF，是否已计划确定性后处理而非只依赖提示词？

任何一项失败，先修配置，不进入提示词编译或生图。

## 6. 提示词编译顺序

写成一个连续中文自然语言段落，按生成执行顺序组织：

```text
风格边界、主笔触与画布
→ 画幅、裁切、人物位置和负空间
→ 角色身份锚点、表情、服装和道具
→ 动作、视线、手势、关系接触机制和遮挡
→ 主动作轴起点、经过位置、终点与空白通道
→ L0 结构锚线
→ L1 塑形排线
→ 必要的 L2 纠正线
→ 必要的 L3 动势线
→ 保护区和低/中/高密度地图
→ 配色、平涂白名单/不填色名单
→ 用户授权的唯一附加效果
→ 用户提供的准确文字
```

没有使用的线层、效果或文字不要硬塞。专业代码可以留在内部；面向通用生图模型时，优先把 L0–L4 转写成可观察的笔触行为。

### 负面约束

只排除当前画面最可能发生的漂移。通用核心是：

```text
无结构归属的随机线团、同粗同亮连续管线、等距波浪、同半径重复卷曲、全画面均匀密度、线条遮住五官和手部接触点、人物融合、多余手指和肢体、光滑矢量线、普通精修动漫线稿、写实素描、未经授权的文字。
```

白底图追加黄白、纸纹和透明背景防线；黑底图追加 3D 霓虹、宽辉光和赛博城市防线。不要禁止当前模式必需的长弧、暗块、点色或平涂。

## 7. 输出动作

- 用户只要提示词：交付风格方案、完整提示词、负面约束；不要附教程。
- 用户明确要生图：使用编译后的完整提示词直接生成，以图片为主要结果。
- 用户要多版：先固定人物、动作、L0 结构和密度地图，每版只改变构图、配色、底色或效果中的一个变量。
- 用户要诊断：先指出一个主要失败及其可见证据；用户要求修复后再重写或生图。

## 8. 生图后质量闸门

按优先级检查：

1. **身份与关系**：人物是否可识别，动作、视线、遮挡、手和接触是否正确。
2. **主轮廓**：脸、五官、发型大形和手势是否能脱离乱线独立读出。
3. **线条归属**：密线是否跟随发束、衣褶、投影或动作轴。
4. **手写自然度**：是否有不规则停顿、重描和笔压差，而非机械卷曲。
5. **密度层级**：是否有低、中、高区，脸手是否仍为焦点。
6. **风格边界**：是否漂成彩铅、水彩、普通精修动漫、厚涂或 3D。
7. **动作与接触**：动作图是否只有一个优势轴；明确接触是否真的相切，自然亲密接触是否清楚而不融合，近接触是否保留用户要求的窄白负空间。
8. **颜色身份**：具名角色的主墨色是否来自可靠角色主色；情侣是否避免机械冷蓝／暖橙。
9. **画布与文字**：白底是否视觉中性、均匀且不透明，是否出现纸纹、可见色偏或未经授权文字；只有用户要求技术纯白时才检查逐像素 #FFFFFF。

## 9. 单变量修正

每轮只修最主要的一项：

| 失败 | 首要修正 |
|---|---|
| 人物或关系不成立 | 修 L0、姿态、遮挡和接触，不先加线 |
| 像 AI 毛线团 | 删除无归属线，重新分配 L1/L2/L3 方向和权重 |
| 太像普通干净线稿 | 增加贴结构的 L2 偏移与笔压差，不增加随机线 |
| 五官或手被覆盖 | 恢复 D0 保护区，降低穿越线权重 |
| 全画面同密度 | 把高密限制到发根、暗面或动作边缘 |
| 动作线四周放射 | 固定主轴起点和终点，删除其他方向射线，只保留平行、汇聚或顺轴延伸的线 |
| 明确要求接触但仍有空隙 | 只移动相关部位，直到用户指定的部位与材质形成真实相切；只有用户明确要求“只有”时才删除其他接触节点 |
| 普通亲密构图被强制露额 | 恢复符合语义的头顶／刘海／发际轻触或手与衣物接触，不把裸露额头当通用模板 |
| 即将接吻却意外接触 | 重新打开鼻尖与嘴唇之间连续、狭窄的纯白负空间，保留靠近姿态与视线张力 |
| 情侣颜色机械蓝橙 | 恢复两名角色各自可靠主色；只有主色不明时才使用关系后备配色 |
| 情绪图漂成彩铅／暖纸 | 恢复默认墨线与白底合同，不改变表情和姿态 |
| 白底黄白或有纸纹 | 只修视觉画布合同，删除实体纸张和光照染色词；像素级纯白需求另走确定性后处理 |
| 双人粘连 | 修两套个人线场、遮挡和纯白分界 |
| 黑底变 3D 霓虹 | 缩窄辉光，恢复手写线压和线密度塑形 |
| 出现文字 | 删除所有文字触发词并声明默认无文字 |

修正完成后重新过一次质量闸门；同一失败最多连续修两轮，再改用更保守的默认配置。
