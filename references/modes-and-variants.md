# 模式、色彩与衍生版本

用于在写 prompt 前选择一个主线模式、必要的辅媒介、颜色策略和版式。不要把所有模式同时组合。

这些是内部导演选项。默认根据用户的一句话自动选择，不要求用户记忆或逐项填写；只有用户要求详细设置或比较方案时才对外展开。

## 一、主线模式路由

| 用户意图／画面特征 | 选择 | 核心笔触 | 不要混入 |
|---|---|---|---|
| 清楚、克制、圆珠笔感 | 定向圆珠笔排线 | L0 清晰，L1 沿发束／衣褶，少量 L2 | 大量随机 L3、粗暗块 |
| 流动长发、作画过程感、情绪弧线 | 轨道弧线／纠正线 | L2 偏移重描＋低权重 L3 长弧 | 规则同心圈、全画面波浪 |
| 深色长发、局部近实色、高密度 | 高密发丝／缠绕线场 | D3–D4 发丝排线、白缝切开、脸部 D0 | 把密线铺进皮肤 |
| 战斗、速度、攻击性 | 尖锐动作爆发 | 折线、射线、强对角 L3 | 柔软圆环主导动作 |
| 哭泣、惊惧、压迫性特写 | 马克笔暗块＋白刮痕 | 粗暗块、飞白、白色划痕 | 全图细线均匀排满 |
| 黑纸、发光反相线稿 | 黑底反相霓虹 | 青白 L0、蓝紫错位 L2、有限辉光 | 赛博城市、金属 3D |
| 明确要求喷溅／半调／柔光 | 多媒介叠加 | 一个主线模式＋1–2 个 L4 效果 | 同时叠加所有效果 |
| 系列海报、情侣拆分、横竖方版本 | 海报／双联画输出 | 一个主线模式＋版式和变体链 | 把它当作独立线条风格 |

默认使用“定向圆珠笔排线”。用户只说“更乱”时不要自动切换模式：先判断他们要的是更明显的重描、更长的动势线、更高的局部密度，还是更粗的媒介。

## 二、模式施工说明

### 1. 定向圆珠笔排线

- L0：脸、眼、手、发型外缘清楚而略深。
- L1：头发按发束分区，衣物按褶皱和受力分区；暗部可以交叉。
- L2：少量贴近轮廓的偏移重描。
- L3：可无，也可只有少量很浅的构造线。
- 适合颜色：单色、角色双色、单点强调、线内渐变。

### 2. 轨道弧线／纠正线

- L0 必须稳定，避免所有轮廓都变成轻飘草图。
- L2 在发束和外轮廓附近反复寻找，偏移不规则。
- L3 可使用数条跨越较大画幅的椭圆片段或长弧，围绕头部、拥抱外形或姿态主轴。
- 长弧通常更浅、更细，靠近脸手保护区时减弱。
- 允许部分回环，但不出现同半径连续绕圈。

### 3. 高密发丝／缠绕线场

- 先画发型大形，再在每束头发内部建立方向不同的 D3–D4 区。
- 深色区域可近似实色，但必须保留白色缝隙、边缘缺口或少量反向发丝。
- 弯曲和回环只在头发范围内发生，服从发旋和发尾。
- 脸部、眼睛、耳朵和手保持 D0–D1。

### 4. 尖锐动作爆发

- 姿态主轴和攻击方向先行。
- L1 使用短促斜排线强调肌肉、衣褶或动物毛发。
- L3 使用射线、折线、锯齿和强对角，方向从动作核心向外扩散。
- 只保留一个主要爆发方向，避免四周均匀炸开。

### 5. 马克笔暗块＋白刮痕

- L0 保证眼睛、鼻口和手势仍可读。
- 将头发、背景边缘或衣物暗面压成不完全覆盖的 D4 粗笔块。
- 用白刮痕、飞白和细线重新切出发丝、泪光和材质方向。
- 可以加少量散景或柔光，但不把暗块做成光滑矢量形。

### 6. 黑底反相霓虹

- 背景为纯黑或近黑负空间。
- 输出为不透明 24-bit RGB，无 alpha 透明通道。
- 青白或蓝白 L0 承担结构；蓝紫 L2 轻微错位。
- L1 仍通过线密度表现发束和衣褶，不依赖体积光。
- 辉光只沿线边缘有限扩散，脸、手和泪珠等焦点最清楚。
- 明确排除数字厚涂、平滑体积塑形、宽辉光和金属 3D。

### 7. 多媒介叠加

先选择 1–6 中的一种主线模式，再选择最多两个辅效果：

- 喷溅：情绪或动作方向；
- 半调：局部阴影或印刷层；
- 柔光／散景：焦点周围；
- 错色副线：线层偏移；
- 局部皮肤色或腮红：情绪；
- 白色高光划线：暗部切分。

效果层不得取代 L0–L2。

## 三、颜色策略

所有白底策略都必须使用同一背景合同：`不透明、中性、均匀的纯白数字画布，RGB 255,255,255（#FFFFFF），无 alpha；不是实体绘画纸`。不得使用“纸白、纸色、数字纸面”代称背景，也不得自动加入米白、暖白、黄白、纸张纤维、颗粒、扫描底色、暗角或光照色偏。真实纸色与纸纹只有在用户明确要求时才能启用。选择性平涂必须同时列出上色白名单和不填色名单。

### A. 单色墨线

默认使用中性 `#FFFFFF` 纯白数字画布，全图锁定蓝、黑、紫、粉、橙或棕中的一种主墨色。颜色差异只来自线的深浅和透明度，不生成物体固有色。角色的红色虹膜、金色耳饰等只作为形状锚点表达，不恢复固有颜色；prompt 同时写出允许色域和禁止回流的固有色。除非用户明确指定实体纸张，否则不允许纸色与纸纹。

### B. 角色冷暖双色

常用于情侣或双联画。人物 A 使用冷蓝／蓝紫，人物 B 使用暖橙／粉棕；相邻处保留未着色的中性纯白或低密度边界。不要让两种颜色随机渐变成全局彩虹。

### C. 单点强调

主图保持单色，只给眼睛、符文、腮红、发饰或领结一个高饱和强调色。面积按视觉功能决定，不硬编码百分比。

### D. 线内渐变

颜色沿线条或人物区域从蓝紫迁移到玫红、暖橙或黄绿；背景纯白不染色。颜色变化跟随画面方向，不按每个小物体分别随机上色。

### E. 选择性平涂

保留主线和排线，只给白名单中的头发局部、皮肤、眼睛、发饰或服装大块平涂；再明确未列出的皮肤、白色衣物、负空间和其他对象保持中性纯白与线稿。平涂可占中等面积，但不能越过白名单，也不能把手写线层完全盖掉。

### F. 较完整彩色

允许角色拥有明确头发、皮肤、眼睛和服装色；用线密度、交叉排线和重描痕迹维持该风格，而不是漂成光滑赛璐璐插画。

### G. 黑底反相

不透明黑色 RGB 背景配青白／蓝紫线，可加入用户明确要求的单一红、金或粉色焦点。背景保持负空间，不自动添加霓虹招牌或城市；不输出 alpha，不漂成数字厚涂或 3D 霓虹渲染。

## 四、版式模板

### 极近景半脸

方幅或横幅，脸可被边缘裁切；头发在边缘形成高密框景，画面另一侧保留大留白。

### 情侣极近景

横幅优先，两张脸相向或额头相触。接触区附近降低 L2／L3 权重，两套头发线场在外围形成方向差。

### 人物靠右横海报

人物占右侧约一半到三分之二，左侧作为标题／负空间。文字低于脸部视觉权重。

### 标题在上的竖海报

上方明显留白，人物落在中下部。标题可为手写块字或克制排版，不添加作者签名。

### 动作方图

主体居中或偏心，强对角贯穿画面；边缘允许动作射线出框。

### 冷暖双联画

分别制作两个朝向中心的单人画面，再输出人物 A、人物 B、双人合成三个版本。中心留白可承接关系张力。

### 同母稿横／竖／方家族

横版强调标题留白；竖版强调人物纵向姿态或顶部留白；方版强调脸、手势或关系接触点。不要只做机械中心裁切，需重新指定主体位置和留白。

## 五、系列输出

用户要求“一组”“多版”“系列图”时：

1. 先写一个母稿 prompt，固定角色、动作、结构、主线模式和密度地图。
2. 再给 2–4 个衍生版本；每版只改变一个主变量。
3. 推荐变量顺序：
   - 单色 → 角色双色或单点强调；
   - 白底 → 黑底反相；
   - 横海报 → 竖海报或方形近景；
   - 纯线稿 → 选择性平涂；
   - 单人拆分 → 双人合成。
4. 不要在同一衍生版同时更换动作、构图、笔触模式、色彩和媒介，否则无法判断哪一个变量有效。

## 六、快速决策

- 用户说“像手绘草稿但别太乱” → 定向圆珠笔排线＋少量 L2。
- 用户说“要那种大弧线、作画痕迹” → 轨道弧线／纠正线。
- 用户说“头发要很密、接近涂黑” → 高密发丝。
- 用户说“战斗、疯感、冲击力” → 尖锐动作爆发。
- 用户说“痛苦、哭、黑压压、白色刮痕” → 马克笔暗块＋白刮痕。
- 用户说“黑底发光” → 黑底反相霓虹。
- 用户说“海报感、左边留字” → 选一个主线模式＋人物靠右横海报。
- 用户说“情侣一人一张还能拼起来” → 选一个主线模式＋冷暖双联画。
