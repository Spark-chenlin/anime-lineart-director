# 提示词示例

示例只演示视觉施工顺序。使用时替换主体、动作、构图和颜色，不复制示例角色；负面约束也要按所选模式删减。

## 1. 定向圆珠笔头像

**完整提示词**

日系动漫手写乱线速写，定向圆珠笔排线模式，不透明纯白数字纸面，1:1 方幅极近景头像，原创短发少女偏右构图，头顶与一侧肩部被画面边缘自然裁切，左侧保留大面积纸白；先用略深、确定的皇家蓝 L0 结构锚线锁定脸型、图形化眼睛、鼻口、发型外缘和触碰脸颊的三根可见手指，眼睛、脸部中心和指尖接触处作为 D0 清晰窗口；L1 细长排线分别沿刘海弧度、侧发下落和衣领受力方向推进，发根与颈下达到 D3，脸颊只留少量 D1 短斜线；L2 重描线贴近发束和肩部轮廓轻微错位，长度、压力、间距与起止自然不齐，背景仅留少量低对比试笔痕迹，全图保持单色蓝墨线和明显的低中高密度差，不进行物体固有色填充。

**负面约束**

无结构归属的随机线团、等距平行网纹、同半径卷曲、全画面同密度、线条遮住眼睛和手指、光滑矢量描边、赛璐璐平涂、写实素描、无意义文字、多余手指。

## 2. 轨道弧线情绪半身

**完整提示词**

日系动漫草稿流半身插画，轨道弧线与纠正线模式，3:4 竖幅，原创长发少年侧身回望，肩线形成向右上方的斜向动势，人物位于中下部并保留头顶负空间；用深蓝紫 L0 锚线清楚建立脸型、眉眼、鼻口、发型大形、外套领口和肩部姿态，脸与回望眼神保持 D0–D1；L1 排线沿发旋向下散开并跟随领口折面，发根和背光肩部局部达到 D3；L2 在发束外缘留下轻重不一、略有偏移的寻找线；L3 使用数条浅蓝灰长弧和不完整椭圆片段围绕头部与肩线运行，部分越出画框，靠近眼睛和手部时减弱，弧线半径、长度与起止各不相同，只服务回望动作和长发流向；纸白保持不染色，不生成完整环境。

**负面约束**

同心圆、连续弹簧线、等距波浪、同粗管线、长弧随机切穿五官、全局均匀铺线、人物结构松散、3D 渲染、完整场景背景。

## 3. 情侣极近景

**完整提示词**

日系动漫情侣手写乱线速写，定向圆珠笔排线为主、低权重共享轨道线为辅，16:9 横幅极近景；长发女孩位于左侧微微仰头，短发男孩位于右侧俯身靠近，两人额头是唯一允许轻触的接触白名单，鼻尖与嘴唇属于非接触名单并分别保留可见纸白细缝，两人视线相锁，女孩靠近镜头，男孩略在后方，肩颈遮挡和双方手部归属明确；先分别以蓝紫 L0 锚线建立两张脸、两套发型、睫毛、鼻口和颈肩关系，额头接触边界、鼻唇细缝、两双眼睛和可见手指构成 D0 保护区；女孩的 L1 线场沿长发向左下方弯曲，男孩的 L1 线场沿短发发束向右上方展开，各自发根和外侧头发达到 D3，相邻轮廓以方向差和纸白细缝区分；L2 只在各自发型与衣领附近轻微错位重描；画面外围加入一到两条很浅的 L3 拥抱弧线，把两个头部纳入同一构图轨道，但接近脸部和额头接触区时自然中断，全图保持不透明纸白 RGB 画布、蓝紫单色、结构清楚、亲密关系优先。

**负面约束**

人物脸部融合、嘴鼻错位、手部归属错误、多余肢体、同一团线缠住两个人、共享长线切穿两张脸、全画面同密度、同半径卷曲、黑底、无意义文字。

## 4. 高密发丝与单点强调

**完整提示词**

日系动漫高密发丝速写，1:1 方幅半脸近景，原创黑长发少女从画面右侧探入，左侧保留纯白负空间，一只手贴近耳侧；以深蓝黑 L0 锚线准确锁定单眼、睫毛、鼻口、耳朵、手指和发型外缘，脸部与手部保持 D0–D1；头发内部按发旋和分束建立多个 L1 向量场，细线在深色发束中达到 D3–D4、局部接近实色，但保留不规则白缝、边缘缺口和少量反向高光发丝，弯曲与局部回环只发生在发束内部并服从发尾走向；L2 纠正线在头发外缘轻微偏移，虹膜加入一个高饱和红色强调点，其余保持蓝黑单色线稿，避免把密线铺进脸部皮肤。

**负面约束**

头发变成均匀网格、同半径毛线圈、密线覆盖脸和手、头发与衣服无边界缠绕、全图实色填满、光滑赛璐璐、写实毛发渲染。

## 5. 马克笔暗块与白刮痕

**完整提示词**

日系动漫高对比情绪特写，粗马克笔暗块与白刮痕模式，3:2 横幅，原创少女哭泣时抬手挡住半张脸，人物贴近画面右侧，左侧保留压迫性的白色空区；先以深靛蓝 L0 结构线准确建立可见眼睛、泪珠、鼻口、手指弯曲和脸手遮挡，再把头发外侧、衣领背光面和画面边缘用不完全覆盖的粗马克笔压成 D4 暗块，暗块边缘保留干涩飞白；用细窄白色刮线切出发丝方向、泪光和衣物折面，少量 L2 深蓝细线贴近脸部轮廓重描，背景只加入稀疏柔焦散景，眼睛、泪珠、指尖和嘴角保持最清晰，不把粗笔块做成平滑矢量色块。

**负面约束**

暗块覆盖五官、白刮痕无方向乱铺、均匀黑色剪影、光滑矢量块、过度散景、3D 体积光、手指粘连、多余肢体。

## 6. 黑底反相霓虹

**完整提示词**

日系动漫黑纸反相手写速写，2:3 竖幅单人半身，原创短发少女蜷缩肩膀并抬手擦泪，人物居中，四周保留大面积近黑负空间；用青白 L0 发光细线建立脸型、眼睛、泪珠、手指和制服边界，蓝紫 L2 副线仅在发束和肩部轮廓轻微错位；L1 在头发与制服背光面以不同方向的密集反相排线形成 D2–D3，脸、眼、泪珠和指尖保持黑底中的清楚窗口；有限辉光只贴在线条边缘，背景不生成霓虹招牌、城市或金属物体，整体仍能看见手写压力、停顿与重描偏差。

**负面约束**

赛博城市、霓虹文字、金属 3D、宽厚体积光、全画面统一发光、线条遮住眼睛和手指、规则双描边、无意义字符。

## 7. 人物靠右的渐变线海报

**完整提示词**

日系动漫手写乱线海报，定向排线＋线内渐变，不透明纸白 RGB 画布、无透明通道，3180:2160 横幅，原创双马尾少女位于画面右侧并占约六成，轻眨一只眼、双手在胸前做清楚手势，左侧保留完整标题区和大面积纸白；L0 锚线准确建立脸型、眼睛、双马尾外缘、每根可见手指和领结，L1 沿双马尾下落、刘海弧度和制服褶皱分区排线，发根与领口背光达到 D3，脸部保持 D0–D1；L2 纠正线在发束边缘自然错位，背景有少量低对比试笔曲线；墨线从画面左侧蓝紫缓慢迁移到人物中部玫红与发梢暖橙，纸白不染色，选择性平涂白名单只有领结的一块红色，皮肤、白衬衫、其余头发亮面和背景属于不填色名单并保持纸白与线稿；只有用户提供的标题写在左侧，字重低于人物眼睛，不添加署名、水印或伪文字。

**负面约束**

人物居中挤掉标题区、背景填满、随机彩虹物体色、渐变染脏纸白、线稿被平涂盖住、无意义文字、作者签名、水印、机械排线。

## 8. 母稿与三个衍生版本

先固定母稿中的角色、动作、L0–L3 和密度地图，再分别改变一个变量：

1. **版本 A：皇家蓝白底单色**——只改变墨线颜色策略。
2. **版本 B：冷暖角色双色**——人物 A 蓝紫，人物 B 暖粉，其余结构不变。
3. **版本 C：黑底反相**——底色与线色反相，保留同一构图与密度结构，辉光有限。

不要在版本 B 或 C 同时更换姿态、裁切、笔触模式和服装。
