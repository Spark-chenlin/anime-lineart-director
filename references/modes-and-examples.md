# 模式、选项与示例

只在用户要求方向比较、详细设置或需要模式示例时读取。所有模式都必须遵守 [视觉语法](visual-grammar.md)，并按 [导演工作流](director-workflow.md) 组合。

## 1. 五种主笔触

主笔触一次只能选择一种。

### A. 定向圆珠笔排线

默认方向。适合普通头像、半身、克制情绪和亲密近景。

- L0 清楚、略深；
- L1 沿发束和衣褶方向；
- L2 少量贴结构偏移；
- L3 通常不用或极浅；
- 结果应像快速但有控制的单色圆珠笔人物稿；墨色可由角色主色决定，不固定为蓝色。

### B. 轨道弧线／纠正线

适合回望、长发流动、安静张力和明显作画过程。

- L0 保持稳定；
- L2 在发束与轮廓附近不规则寻找；
- L3 使用少量不同半径、不同起止的长弧；
- 长弧接近脸手时减弱，不能变成同心圆或弹簧线。

### C. 高密发丝场

适合深色长发、局部接近实色和强烈发丝质量。

- 先锁定发型大形，再按发旋拆分多个向量场；
- 发根和暗面可达 D3–D4；
- 保留白缝、边缘缺口和反向高光发丝；
- 脸、耳朵、手和接触点保持 D0–D1。

### D. 尖锐动作线

适合战斗、速度、冲击和攻击性姿态。

- 先确定唯一动作轴；
- 写清轴线起点、经过的受力关节和终点，例如“左上后方 → 肩肘双手 → 右下出框刀尖”；
- L1 使用短促斜排线；
- L3 只能与主轴平行、向终点汇聚或沿轴延伸，轴线两侧保留低密度通道；
- 不能从四周均匀爆炸、形成第二组射线，也不由柔软圆环主导。

### E. 马克笔暗块＋白刮痕

适合哭泣、惊惧、压迫和高对比特写。

- L0 先锁定可见五官、泪珠、手势和遮挡；
- 头发或衣物暗面形成不完全覆盖的 D4 暗块；
- 用白刮痕、飞白和细线切回结构；
- 暗块不能成为光滑矢量剪影；
- 白刮痕是该主笔触的内置组成，不再额外叠加轨道椭圆、外围长弧或其他竞争性主效果。

## 2. 构图策略

- **极近景头像**：脸占画面一半以上，可裁切头顶或肩部；头发和边缘高密，脸部留白。
- **单人半身**：先确定肩线和手势，以衣褶方向承接姿态。
- **人物偏置海报**：人物占一侧约 50%–70%，另一侧保留纯白负空间；没有用户文案时保持空白。
- **动作方图**：主体居中或偏心，唯一强对角贯穿画面。
- **情侣极近景**：两张脸相向、平行或轻触；接触区低纹理，两套个人线场方向不同。
- **角色主色双联画**：先分别完成朝向中心的单人母稿，再组合；优先沿用双方各自主要识别色，这是版式，不是笔触。
- **同母稿横／竖／方**：保留身份、动作和线层，重新安排主体位置与留白，不做机械裁切。

## 3. 画布与配色

### 默认：受控单色＋纯白数字画布

先使用用户指定色；否则从具名角色最可靠的主要识别色中选一种作为完整墨线系统；原创角色可从皇家蓝、蓝紫、深靛、墨绿、玫红或橙棕中选择一种。无法可靠判断时才回退皇家蓝。角色固有色被转译为墨线主色，不等于恢复完整物体上色。白底使用视觉语法中的视觉背景合同。

### 单点强调

主图保持单色，只给一个眼睛、符号、腮红、发饰或领结明确点色。不要扩散成完整上色。

### 角色主色双墨

人物 A、B 分别使用各自最可靠的主要识别色作为整套个人线场；相邻边界保持纯白或低密度，不混成第三色。只有角色主色不明确且关系构图需要区分时，才从冷蓝／蓝紫与暖橙／粉棕中选择后备组合。不要形成全局彩虹。

### 线内渐变

颜色只沿线条或人物区域迁移，跟随构图方向；#FFFFFF 背景不染色。

### 选择性平涂

列出允许上色对象和不填色对象。平涂不能盖掉主轮廓、排线和纠正线。

### 较完整彩色

只有用户明确要求完整上色时启用。保留明显 L0–L2、局部排线和重描，不转为光滑赛璐璐。

### 黑底反相

只有用户明确要求黑底、反相或发光时启用。使用不透明黑色 RGB 画布、青白主线、少量蓝紫错位副线和有限线缘辉光；不添加城市、招牌、金属 3D 或宽体积光。

## 4. 附加效果

默认不用，自动选择最多一个：

- 外围关系弧线：连接情侣或整体姿态；
- 喷溅：强调唯一动作方向；
- 半调：局部印刷阴影；
- 错色副线：少量轮廓偏移；
- 白刮痕：从暗块中切出发丝、泪光或材质方向；
- 有限辉光：只用于明确的黑底反相；
- 双联分割：只用于系列或关系版式。

柔焦、散景、纸张纹理不属于默认参考风格，不得因“温柔、梦幻、怀旧”自动加入。

马克笔暗块模式已经包含白刮痕，黑底反相已经允许有限辉光；这类内置成分不再计作额外可自由叠加的效果，也不能借此加入第二种主笔触。

## 5. 对外选择方式

不要向普通用户展示完整内部菜单。用户要求“给我几个方向”时，根据其需求选出最多三个，例如：

1. 清楚利落的蓝色圆珠笔速写；
2. 纠正线和长弧更明显的作画草稿；
3. 发丝与衣服暗部更密的情绪稿。

选择名称要描述最终视觉差异，不要求用户理解代码或参数。

## 7. 完整提示词示例

用户输入：“画一对刚确认关系、很害羞的动漫情侣，额头轻触。”

风格方案：

```text
定向圆珠笔排线 + 情侣极近景 + 角色主色双墨纯白底 + 低权重外围关系弧线
```

提示词示例：

```text
日系动漫手写乱线速写，使用清楚而有手压变化的圆珠笔式线层；采用视觉语法规定的、不透明中性纯白数字画布。16:9 横幅极近景，暖棕长发女孩在左侧微微仰头，使用暖棕玫红墨线建立完整个人线场；蓝黑短发男孩在右侧俯身靠近，使用深靛蓝墨线建立完整个人线场；两种线色不混成第三色。两人神情害羞、视线相锁；先摆放头部，使两眉上方中央的裸露额头轮廓形成一个明确、连续、没有可见白缝的皮肤相切节点，同时不互相穿透；该节点是两个人物轮廓唯一允许合并的位置。双方刘海向外退开，发丝终点与皮肤节点之间保留纯白隔离，鼻尖、嘴唇、头发和发际线均不接触。先用较确定的主轮廓锁定两张脸、两套发型、五官、肩颈遮挡和可见手部；女孩排线沿长发向左下弯曲，男孩排线沿短发向右上展开，发根和外侧头发较密，脸、眼睛、嘴唇、额头相切节点和手指保持低纹理；在各自发型与衣领附近加入少量不规则偏移的纠正线，接触节点附近不放纠正线；画面外围仅用一条浅淡、不闭合的关系弧线收住两个头部，靠近脸部时自然中断；全图保持两套受控角色主色线场和明显低中高密度差，无完整场景，无文字。
```

负面约束示例：

```text
人物融合、额头仍有可见空隙、额头大面积重叠、手部归属错误、接触点落在刘海或发际线、鼻唇误接触、两种角色主色混成第三色、无结构随机线团、共享长线切穿两张脸、同半径卷曲、全画面同密度、普通精修动漫线稿、彩铅、水彩、黄白纸张、纸张纹理、背景色偏、无意义文字。
```

## 8. 系列图

先固定母稿中的角色身份、动作、L0 结构、主笔触和密度地图，再生成 2–4 个版本，每版只改变一个变量：

- 构图：横幅 → 竖幅；
- 配色：受控单色 → 角色主色双墨或单点强调；
- 底色：白底 → 用户明确要求的黑底反相；
- 上色：纯线稿 → 用户明确要求的选择性平涂；
- 关系输出：单人拆分 → 双人合成。

同一版本不得同时改动作、裁切、主笔触、配色和媒介，否则无法判断变量效果。
