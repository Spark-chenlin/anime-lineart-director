# 视觉语法：参考风格的唯一事实来源

本文件记录从参考作品中归纳出的视觉规则，是本 Skill 执行时使用的风格依据，无需另行获取原始参考图片。其他文件负责选择与执行，不重复定义风格；生成效果示例见[作品画廊](https://lineart.chenlinplay.top/)。

## 1. 风格定位

核心公式：

```text
清晰动漫母稿
× 多速度手写线层
× 有结构归属的局部密度场
× 中性纯白数字负空间
× 克制的海报化组织
```

它不是普通干净动漫线稿，也不是随机乱线、实体纸张彩铅、写实素描或精致赛璐璐插画。可信的“手写感”来自寻找、停顿、重描、方向和密度差，而不是线条总量。

## 2. 封闭视觉边界

默认允许：

- 图形化动漫脸、清楚发型大形、明确手势和姿态；
- 蓝／深靛、黑／炭黑／石墨灰、蓝紫／玫粉、红／暖橙／橙棕、青蓝／蓝绿、角色可靠主色或用户指定的受控墨线；
- 沿发束、衣褶、投影和动作轴运行的排线；
- 贴近结构、不规则偏移的纠正线；
- 局部极密与大面积低纹理留白同时存在；
- 少量关系弧线、动作射线、点色或海报分割。

没有用户明确授权时禁止：

- 米白、暖白、泛黄、纸纤维、扫描颗粒和实体纸张质感；
- 彩铅、水彩、油画、粉彩、厚涂、光滑赛璐璐和普通精修线稿；
- 柔焦、散景、宽辉光、3D 霓虹、金属体积塑形；
- 完整场景透视、装饰性背景填充、未经授权的签名、水印和任何自动文字。

情绪词不能解除边界。“温柔、青春、恋爱、怀旧”只影响人物关系、表情、姿态和线条节奏。

## 3. L0–L4 线层

### L0 结构锚线

- 锁定身份、脸型、五官、发型外缘、手指、衣领、道具、姿态和接触边界。
- 比其他线更确定、略深，但仍保留轻微手压变化。
- 隐藏其他线层后，人物与关系仍必须可读。

### L1 塑形排线

- 沿发旋、发束、衣褶受力、颈部转折、投影或表面方向运行。
- 亮部稀，转折中等，发根和背光面可高密。
- 允许局部交叉和近实色，但不能脱离物体方向形成均匀网纹。

### L2 重描纠正线

- 贴近 L0/L1 轻微偏出，呈现寻找和修正。
- 起止、偏移、长度、压力和透明度不恒定。
- 权重通常低于 L0，不做规则双描边，也不覆盖身份区。

### L3 动势轨道线

- 只服务头部轨道、长发流向、拥抱关系、姿态主轴或攻击方向。
- 可用长弧、椭圆片段、扫线、射线和折线。
- 通常位于轮廓外或负空间，靠近脸、手和接触点时减弱或中断。
- 明显跑跳、攻击或挥击先定义一条有起点和终点的主动作轴；主要射线与其平行、向终点汇聚或沿轴延伸，轴线两侧保留可见空区。普通姿态不强制展开动作轴。
- 禁止同半径循环、等距波浪和随机穿脸打结。

### L4 附加效果

- 可选喷溅、半调、错色副线、白刮痕、飞白或有限辉光。
- 一张图最多自动加入一种；用户明确要求时才可增加。
- 只能服务暗部、边缘、动作或焦点，不能取代 L0–L2。

不需要每张图强行使用全部线层。默认头像可只用 L0–L2；动作图再加强 L3；特殊媒介才使用 L4。

## 4. 密度地图

- **D0 保护区**：眼睛、鼻口、脸部中心、指尖、接触点；只保留必要结构线。
- **D1 轻区**：面部边缘、颈部亮面、浅色服装、少量纠正线。
- **D2 中区**：普通发束、衣褶、下颌和颈部投影。
- **D3 高区**：发根、深色头发、衣物背光和强阴影。
- **D4 暗块区**：只用于高密发丝或马克笔暗块，必须由白缝、刮痕或可读边缘重新切开。

画面至少出现低、中、高三级密度。高密度不能均匀扩散到全图。

### 4.1 笔触强度路由

笔触强度是所选主笔触的内部子参数，不是另一种风格，也不向普通用户显示为必选菜单。强度只改变结构线、塑形排线与寻找重描之间的显著程度，不改变角色、构图、颜色或媒介。

- **轻量**：只在用户明确要求“干净、少线、清爽、轻淡”时启用。L0 仍清楚，L1/L2 有但克制，允许局部高密区较小；不能退化成普通精修线稿。
- **参考标准**：未指定时的默认，覆盖参考语料的主流笔触。L0 比辅助线略深；头发或衣物暗部至少有一个方向明确的 D3 局部；发缘、肩线或衣褶附近可见浅淡、不规则偏移的 L2；脸、手与接触／无接触通道保持 D0–D1。
- **高密**：用户明确要求“密、压黑、强烈笔触”，或深色长发、强阴影、压迫、快速动作确实需要时启用。增加的是授权区域内的 L1 密度、线压差和有限 L2，不是全画面线量；仍必须保留白缝、低密区和结构可读性。

强度只能落在头发、衣物暗面、投影、动作轴等已授权区域。不得用均匀网格、同权重交叉线或铺满画面的浅线模拟强度，也不得把眼睛、鼻口、脸部中心、手指和关系节点变成纹理区。默认参考标准的可观察成立点是“有一处明显密、有几处轻微找线、焦点仍干净”，而不是“每处都画得很多”。

## 5. 手写感与 AI 式乱线

| 可信手写线 | AI 式混乱 |
|---|---|
| 能回指发束、衣褶、投影或动作轴 | 像覆盖画面的无方向纹理 |
| 同组方向相近，但长度、压力和间距不同 | 同粗、同亮、等距、等长 |
| 纠正线贴近结构并不规则偏移 | 围绕轮廓生成机械双描边 |
| 长线承担构造或动势，权重低于焦点 | 随机穿过脸、手和不同物体 |
| 局部可极密，仍有呼吸和保护区 | 全画面同密度 |
| 曲线半径受发束或动作约束 | 同半径线圈、弹簧、均匀波浪 |
| 能感到起笔、停顿、回找和收笔 | 连续管线没有自然起止 |

不要用“更乱、更多 scribble”解决手写感不足。优先增加有归属的 L1、轻微 L2 偏移和笔压差。

## 6. 人物结构与构图

### 单人

- 头像：眼睛和脸部中心形成 D0 窗口，头发与边缘承担高密度。
- 半身：先确定肩线和手势，再让衣褶排线承接姿态。
- 动作：先写一个动作骨架——支撑／发力位置、整体方向和手部任务。只有快速位移、攻击或挥击需要进一步展开主要动作轴；射线和折线从人物后方、肩背或动作起点沿轴指向武器、拳头、脚部或移动终点，不能从四边同时把主体围成爆炸中心。
- 海报：留白是版式区，不得自动补成完整环境。

### 姿态风险与可解性

动作变化本身不是风险漂移，但自动导演不需要用最难的人体组合证明“有变化”。先按风险分级，再决定需要多少结构信息：

- **低风险默认池**：正面或三分之四侧面、头肩自然同向、抬眼／垂眼／侧视、前倾、坐姿、依靠、整理领口或袖口、近侧手别发／挡光／持物。优先用这些变量与机位、景别和构图组合出差异；
- **中风险按需池**：轻度回望、头肩方向略有差异、手靠近脸、手臂穿过身体中心、明显俯仰。自动导演可用，但必须补足身体朝向、头肩关系、手的左右归属和支持动作的裁切；
- **高风险非默认池**：身体背向镜头同时大幅回头、躯干反向扭转同时触脸、远侧手跨越身体、紧裁切承载完整复杂手臂动作、多人手臂交叉并共同持物。不得为了随机变化自动选取；用户明确要求或该姿态对主事件不可替代时才保留，并通过完整可解链检查；
- **高动态姿态**：明显跑跳、攻击、挥击或高速位移，另使用唯一动作轴，不等同于高风险扭转。

中／高风险姿态的内部可解链为：`身体朝向 → 头肩关系 → 手的左右归属 → 可见肩／肘区域 → 前臂方向 → 手部任务 → 支持该链条的裁切`。最终提示词用一两句自然语言压缩，不逐关节罗列。若链条与人物位置、留白方向或视线要求冲突，优先重新安排从属构图和景别；用户明确要求的动作要保留，自动导演自行加入的高风险动作则回退到能表达相同事件的低／中风险方案。

### 动作骨架与动作轴

普通站姿、坐姿、依靠、拥抱和小幅互动只需说明：身体由哪里支撑或依靠、整体朝向哪里、可见的手在做什么。不要为了“完整”逐关节描述人体。

明显跑跳、攻击、挥击或高速位移才进一步明确：

1. 轴线起点：人物后方、支撑脚、肩背或蓄力位置；
2. 轴线经过：躯干、肩肘、手腕或主要受力关节；
3. 轴线终点：刀尖、拳头、脚尖或画外移动目标；
4. 主要速度线：与轴线平行、向终点汇聚或顺轴延伸；
5. 空白通道：轴线两侧至少有一侧保持低密度，不出现第二组相反或径向射线。

“主体动作可读”但“辅助线四周放射”仍判为动作轴失败。

### 双人／情侣

依次确定：

1. 人物 A 的位置、朝向、可见范围和个人线场；
2. 人物 B 的位置、朝向、可见范围和个人线场；
3. 脸、头发、肩颈和手部的前后遮挡；
4. 允许接触的部位与材质；
5. 必须保留纯白细缝的非接触部位；
6. 一个可选、低权重的共享关系场。

共享关系场只能通过外围负空间表达拥抱弧线、视线轴或共同动势，不能以主轮廓同等强度切穿两张脸。

#### 开放式关系事件

双人／多人不从封闭姿势菜单中选“情侣模板”，而是先形成一个可一句话说清的主关系事件。内部关系卡为：

```text
关系意图
+ A/B 位置与朝向
+ 距离和接触拓扑
+ 支撑／重量关系
+ 手部、道具与遮挡归属
+ 视线和情绪
+ 支持关系可读的构图裁切
```

一个画面只保留一个主要关系事件。可表达恋爱、友情、亲情、对峙、竞争、守护、协作或擦肩而过；可使用面对面、并肩、背靠背、头靠肩、拥抱、牵手、拉衣领、触脸、扶住、共同持物等方式，但这些只是按语义选择的例子，不是穷举路由。先让位置、距离、承重和归属共同成立，再决定是否需要接触。

三种高频关系结果仍可作为局部处理方法：

- 用户明确说“额头相贴、牵手、拥抱”等动作时，让指定接触成为清楚视觉节点，不能用“非常靠近”替代；只有出现排他措辞时才限制其他接触；
- 用户只说“靠近、依偎、亲密对视、头靠在一起”时，以姿态、视线和少量自然关系节点表达亲密，不在提示词中穷举候选位置；
- 用户说“即将接吻、脸很近但不要碰”时，以人物之间可见、连续的纯白间隔表达未接触状态，辅助寻找线在关系通道外终止。

精确接触属于高难度按需模式。只有用户明确给出接触部位和排他条件时，才在内部确定：一个允许接触区、一个需要保持分离的主要区域，以及接触区附近的低纹理保护。最终提示词优先使用正向几何，例如“裸露额头形成唯一清楚触点，鼻唇之间保持白色间隔”；不要再逐项列出刘海、发际线、发饰、每根发丝等所有禁止对象。需要返图修复时，才针对实际失败增加一条局部约束。

复杂共同持物、十指相扣或遮脸动作，先确定每只手属于谁、从哪里伸来以及要完成什么抓握／遮挡结果。只有手部是主成立点或返图已经出现归属错误时，才追加掌缘、拇指或可见指缝等局部几何；不要默认逐指展开。

## 7. 白底背景合同

所有未明确指定其他底色的图像必须使用这一视觉合同：

```text
以 RGB 255,255,255（#FFFFFF）为目标的不透明、中性、视觉均匀的纯白数字画布，无 alpha；这是屏幕白色负空间，不是实体绘画纸。背景和未着色负空间不得出现可见的米白、象牙白、奶油白、暖白、黄白、泛黄、纸张纤维、颗粒、扫描底色、暗角、光照渐变或冷暖色偏。
```

规则：

- 不使用“纸白、纸色、数字纸面、素描本、水彩纸”等背景代称。
- “留白”始终表示未着色的 #FFFFFF 数字负空间。
- 角色授权色、点色和线内渐变不能染色背景。
- 只有用户明确要求实体纸张、复古纸或暖色底时才解除合同。
- 普通生成的通过标准是视觉中性、均匀、不透明、无纸纹和无可见色偏；模型输出中 252–255 的近白抗锯齿或轻微数值浮动不单独判为风格失败。
- 用户明确要求文件像素严格等于 #FFFFFF 时，必须在生成后使用确定性背景归一化并检查像素；不能声称仅靠提示词已满足技术合同。

## 8. 颜色与媒介边界

先选择一种配色策略，再选择具体色相。一张图只能有一种主配色策略；点色可以作为受控单色的从属强调，但线内渐变、选择性平涂、较完整彩色和黑底反相不能同时竞争。

### 8.1 色相路由

未指定色相时按以下顺序自动选择：

1. 用户已经给出的颜色；
2. 具名角色有把握的主要识别色；
3. 原创角色由发色、服装大色块和画面主题推导的一种参考内墨色；
4. 信息不足时使用皇家蓝安全回退。

角色主要识别色在默认路径中被转译为完整墨线系统，不自动恢复肤色、服装和环境的全部固有色。参考内自动色域为：

- 蓝色系：皇家蓝、克莱因蓝、深靛；
- 中性色系：黑色、炭黑、石墨灰；黑色墨线不等于黑底反相；
- 紫粉系：蓝紫、玫紫、玫粉；
- 暖色系：红色、暖橙、橙棕；
- 青色系：青蓝、蓝绿色；
- 角色可靠主色或用户指定的其他受控墨色。

墨绿不是常规自动中心色；只有角色身份、用户要求或明确主题支持时才使用。色名表示方向而非固定色值，仍通过线深、透明度和密度建立层级。

### 8.2 配色策略

- 受控单色：普通单人和未明确彩色要求时的默认策略；不要求所有未指定图片都回到皇家蓝。
- 单点强调：只给用户指定、身份必要或构图必要的眼睛、发饰、符号等一个强调色。
- 角色主色双墨：身份区分重要的情侣或双联优先使用；人物 A、B 分别使用各自最可靠的主要识别色作为完整个人线场，非接触边界保持纯白，真实触点保持低纹理且不混成第三色。用户明确要求统一关系色时可以共享一种主墨色；冷蓝／暖橙只是角色主色缺失时的后备关系配色，不是情侣固定公式。
- 多人：优先使用共享主墨色，通过线深、密度和最多一到两个身份点色区分；不要给每个人随机分配一种颜色。
- 线内渐变：只有用户明确要求或系列任务把配色作为单一变量时启用；颜色只沿线层或人物区域迁移，背景保持 #FFFFFF。
- 选择性平涂：只有用户明确要求局部上色时启用；必须列出允许上色白名单和不填色名单。
- 较完整彩色：只有用户明确要求才启用；必须保留可见 L0–L2，不得漂成光滑赛璐璐。
- 黑底反相：只有用户明确要求黑底、反相或发光时启用；使用不透明黑色 RGB 画布和青白／蓝紫细线，辉光窄而有限，禁止赛博城市、金属 3D 和宽体积光。

同母稿变体可以单色换色、单点强调、线内渐变、局部平涂或黑底反相作为逐版单一变量；不得同时改变人物、动作、裁切、主笔触和配色策略。系列角色组图可以根据不同角色的可靠主色逐张变化，但每张仍只能选择一种主配色策略。

## 9. 按需文字合同

默认无文字。角色名和署名属于用户明确授权后才出现的构图内容，不是默认装饰，也不是新的主笔触、附加效果或完整标题海报模式。所有授权文字必须与人物、留白和墨色在同一次生成中一体式设计；不得生成无字母稿后再以图层、贴图或水印叠加。

### 9.1 内容锁

- 用户给出具体文字时逐字使用，不翻译、不改写、不改变大小写；
- 用户只说“加署名”而没有另给内容时，使用预设署名 `ChenLin`；
- 用户只说“加角色名”时，只能使用当前请求中已经明确写出的角色名；当前请求没有角色名时问一个最短问题，不编造日文、罗马字或别名；
- 用户同时要求角色名和署名时，角色名使用上条内容锁，次级署名使用 `ChenLin`；
- 用户说“不要文字”或“不要署名”时，以其排除要求为准；
- 不自动添加 `by`、作品名、账号、品牌、日期、编号、宣传副标题或伪字符。

### 9.2 三种文字结构

1. **独立作者署名**：小型个人手绘落款，位于人物外侧的安全负空间，使用主墨色或邻近点色。字形自然倾斜，基线轻微起伏，字距和字形大小不完全相等，可有局部连笔与一处克制的下划线或延长收笔；视觉权重显著低于人物。
2. **独立角色名／角色字标**：作为较明显的单一文字锚点放入人物外侧留白。英文允许自由手写、轻微倾斜与不规则基线；中文或日文按负空间形状选择横排或竖排，但必须使用用户提供的准确文字。字标可以明显，但仍不得压过人物眼睛、脸部与动作／关系焦点。
3. **角色名＋小型作者署名**：角色名是一级字标，`ChenLin` 是靠近其下方或侧下方的二级落款；署名约为角色名字号的 20%–35%，允许轻微错位，不做机械居中或字库式对齐。两级文字共同形成一个文字组，不再加入第三层信息。

### 9.3 构图与字形

- 先确定人物、动作轴、接触／无接触关系和主要留白，再选择文字位置；
- 优先使用右下、左下或人物轮廓外侧的留白；角色字标可使用更大的侧向留白；
- 不遮挡眼睛、脸、手、身份锚点、人物接触点、情侣关系通道或动作图的主轴和速度通道；
- 文字颜色服从当前主墨色或邻近点色，不引入新的全局配色策略；
- 署名与角色字标要保留手绘起笔、停顿、连写和收笔差异，不得呈现为手机系统手写字体、规整字库、标准书法字帖、印刷标题、品牌 Logo 或独立水印；
- “艺术字体”不是充分描述；必须写出可观察的笔势、基线、字距、层级和留白关系。

生成模型仍可能误写文字。质量检查必须同时验证准确内容、唯一实例、层级、位置和手写自然度；失败时只修文字这一变量并最多自动重新生成一次。重试后仍失败就停止并向用户说明剩余问题，不改用后期叠加来伪装通过。

## 10. 风格失败判定

以下任一情况成立即视为需要修正：

- L0 无法独立读出人物、动作或关系；
- 高密度线无法回指结构；
- 全画面同权重或脸手被纹理覆盖；
- 大量同半径卷曲、等距波浪、机械网格或连续管线；
- 动作图出现第二组主轴、四周径向爆线或主体被包围成爆炸中心；
- 双人身份融合、手部／道具／承重归属错误、主关系事件不可读、接触点漂移；用户明确要求接触时仍有可见空隙，或明确要求近接触时反而发生意外触碰；
- 复合姿态中手掌无法沿前臂、肘与上臂回接正确肩膀，头颈与躯干转向断裂，或裁切切掉了动作成立所需的关键连接；
- 用户未要求裸露额头或唯一接触，却把所有亲密关系机械改成露额相贴或删除合理的第二关系节点；
- 默认白底出现可见黄白色偏、纸张纹理、暗角、环境染色或透明通道；
- 未授权出现完整上色、彩铅、水彩、柔焦、3D、场景或文字。
