# 日系动漫手写乱线速写视觉语法

用于精确控制线条层级、密度、人物关系和返图诊断。具体子模式、色彩和输出家族见 [模式与变体](modes-and-variants.md)。

## 风格定位

这是一套“清晰动漫母稿 × 多速度手写线层 × 局部密度场 × 海报化衍生”的视觉系统。它既可以很轻，也可以让头发和衣物局部接近实色；可信度取决于每类线为什么存在，而不是线条总量。

## 画面设计顺序

1. **动漫母稿**：先成立脸型、眼睛、发型大形、手势、姿态和遮挡。
2. **保护区地图**：眼睛、鼻口、脸部中心、手指、接触点保持低纹理。
3. **结构向量场**：为每束头发、衣褶、投影和动作轴规定笔触方向。
4. **线层叠加**：依次加入 L0–L4，不让后层破坏前层。
5. **色彩与媒介**：选择一种颜色策略和必要的辅效果。
6. **版式衍生**：再决定横竖方裁切、标题区、单人拆分或双人合成。

## L0–L4 线层

### L0 结构锚线

- 作用：确认人物身份、表情、动作和关系。
- 区域：五官、脸型、发型外缘、手指、衣领、道具、接触边界。
- 质感：比其他线更确定，局部可连续；粗细仍有手压变化。
- 验收：隐藏其他线层后，人物与关系仍可读。

### L1 塑形排线

- 作用：表达头发质量、衣褶、暗面和表面转折。
- 方向：沿发束下落／弯曲、衣物受力、颈部转折和投影方向。
- 密度：亮部稀、转折中等、深色发根或背光面可非常密。
- 允许：局部交叉、近实色排线、在发束内部出现少量弯曲与回环。
- 失败：脱离物体方向的均匀网纹，或从一个物体同强度缠到另一个物体。

### L2 重描纠正线

- 作用：制造真实作画中的寻找、犹豫和修正。
- 位置：贴近 L0 或 L1，轻微偏出轮廓；也可在发束内部重复。
- 质感：起止不齐、偏移幅度不恒定、轻重不同，不做规则描边副本。
- 权重：通常低于 L0；局部可重叠但不覆盖身份区。

### L3 动势轨道线

- 作用：表现头部轨道、流动长发、拥抱弧线、攻击方向或整体情绪。
- 形状：长弧、椭圆片段、扫线、射线、折线。
- 位置：轮廓外、背景负空间或主体外围；可以跨越较大画幅。
- 权重：通常细、浅、稀；动作爆发模式可变深，但必须沿统一动作轴。
- 允许：部分闭合、跨越人物外围负空间、穿过低优先级背景。
- 失败：同半径循环、等距波浪、随机打结，或以 L0 同等强度切穿脸和手。

### L4 媒介效果层

- 作用：建立特定成品质感。
- 可选：粗马克笔暗块、白色刮痕、飞白、喷溅、半调网点、错色副线、有限辉光或散景。
- 限制：一张图通常只使用一到两种效果；效果必须集中在暗部、边缘或背景，不均匀覆盖全图。

## 手写式混乱与 AI 式混乱

| 手写式混乱 | AI 式混乱 |
|---|---|
| 线条能回指发束、衣褶、投影或动作轴 | 线条像贴在画面上的无方向纹理 |
| 同一组方向相近但长度、压力和间距不同 | 同粗、同亮、等距、等长 |
| 重描线贴近结构并有不规则偏移 | 线条围绕物体生成规则双描边 |
| 长弧承担构造或动势，权重低于焦点 | 长线随机穿过脸、手和不同物体 |
| 局部可极密，画面仍有低中高层级 | 全画面同密度、没有视觉呼吸 |
| 回环的半径和形状受头发／动作约束 | 重复同半径线圈、弹簧和均匀波浪 |
| 起笔、收笔和停顿可感知 | 连续管线没有自然起止 |

不要通过“少画线”来替代手写感。先让线条角色和密度层级成立，再决定数量。

## 密度地图

密度使用相对等级，不使用固定根数：

- **D0 保护区**：眼睛高光、鼻口、脸部中心、手指尖、嘴唇／额头等接触点。允许必要结构线，不铺装饰纹理。
- **D1 轻区**：面部边缘、颈部亮面、浅色服装、轮廓外纠正线。
- **D2 中区**：普通发束、衣褶、下颌和颈部投影。
- **D3 高区**：发根、深色头发、衣物背光、强阴影和盔甲转折。
- **D4 暗块区**：仅在高密发丝或马克笔模式使用，可接近实色；必须由白缝、刮痕或可读边缘重新切开。

默认让 D0–D3 至少出现三级。背景不固定为低密：海报留白模式通常 D0–D1，轨道弧线模式可出现少量 D2 长弧，动作爆发模式可出现定向 D3 射线。

## 构图与裁切

### 极近景头像

脸占画面约一半以上，可切掉头顶、肩膀或半张脸。密线集中在头发和画面边缘，眼睛与脸部中心形成白窗。

### 单人半身

先确认肩线和手势，再以衣褶方向承接排线。人物可居中，也可偏置为标题留白。

### 人物靠右的横海报

人物约占 50%–70%，左侧保留标题或纯白负空间。L3 可把人物动势轻微带向空白区，但不能把空白填成均匀背景纹理。

### 标题在上的竖海报

上方保留明显空区，人物落在中下部。不要为了“填满画面”把头顶留白改成完整场景。

### 动作方图

姿态主轴明确；L3 使用锯齿、射线和强对角线。面部和动作关键点仍由 L0 锁定。

### 极近景双人

两个头部形成相向轴、平行轴或拥抱弧线。鼻尖、额头、嘴唇或手部接触点位于视觉中心附近；头发可以在外围形成高密框景。

### 冷暖双联画

先分别完成两张单人母稿，再通过相反朝向、中心留白和冷暖墨色合成。不要把双联画理解成把两个人随机塞入同一张图。

## 双人关系线场

双人图依次建立：

1. 人物 A：位置、朝向、可见范围、头发与衣物方向。
2. 人物 B：位置、朝向、可见范围、头发与衣物方向。
3. 遮挡顺序：哪张脸、哪束头发、哪只手在前。
4. 接触白名单：只允许哪些部位触碰；同时列出鼻尖、嘴唇、手指等必须保留纸白细缝的非接触名单。
5. 两套个人线场：分别服务各自结构。
6. 一个可选共享关系场：拥抱外轮廓、视线轴、环抱弧线或背景轨道。

共享线场不是第三团乱线。它通常比 L0 浅，只能穿过外围负空间；接近两张脸、手和接触点时减弱或停止。头发相邻处用方向差或明度差分开，不必强制所有线完全不交叉。

## 媒介行为

- **数位细笔／圆珠笔**：细长、快速、轻微压感变化；适合 L0–L3。
- **铅笔式纠正线**：更浅、更软，只用于 L2／L3，不承担最终五官。
- **粗马克笔**：压成 D4 暗块；边缘带飞白或不完全覆盖。
- **白色刮线**：从暗块中切出发丝、泪光或材质方向。
- **喷溅墨点**：集中在背景边缘或情绪方向，不覆盖脸手。
- **半调网点**：作为局部印刷层，不替代全部阴影。
- **辉光／散景**：有限、低频，只服务反相线或情绪焦点。

## 常见失败与单变量修正

| 失败 | 优先修正 |
|---|---|
| 像普通干净线稿 | 增加 L1 定向重描和 L2 轻微错位，保留 L0 |
| 像 AI 毛线团 | 不先减总线量；先删除无归属线，分开 L1、L2、L3 的方向和权重 |
| 同半径线圈／弹簧 | 把曲线重新绑定发束或动作轴，改变半径、起止和透明度 |
| 五官消失 | 恢复 D0 保护区，降低穿脸线权重，不动其他区域 |
| 头发像均匀网格 | 按发旋和发束拆成多个向量场，亮暗密度不同 |
| 背景抢主体 | 降低 L3 数量或对比，不必删除所有长弧 |
| 太干净但继续加线后更乱 | 增加重描偏移和笔压差，不增加无方向覆盖 |
| 双人粘连 | 先修遮挡和接触边界，再用两套笔触方向区分人物 |
| 双人不亲密 | 修正脸部距离、视线、肩颈和手部关系，不用随机跨人物线补情绪 |
| 唯一接触点漂移 | 同时写“允许接触白名单”和“必须留缝的非接触名单”，不要只描述靠近 |
| 平涂破坏线稿 | 若非彩色模式，缩小平涂区域；若是彩色模式，恢复 L0–L2 的可见度 |
| 选择性平涂扩散 | 列出允许上色对象及不填色对象，白色衣物、皮肤或负空间不应被自动补色 |
| 白底变透明／预览成黑底 | 强化“不透明纸白 RGB 画布、无 alpha 透明通道”，删除未选择的反相与故障效果 |
| 黑底变 3D 霓虹 | 限制辉光宽度，保留手写错位和线密度，不加金属体积光 |
| 海报留白被填满 | 明确留白是版式区，不生成环境透视或装饰纹理 |

## 提示词覆盖审计

交付前确认：

- 主线模式明确，辅媒介不超过必要数量；
- 画幅、裁切、人物位置和负空间明确；
- 身份锚点、表情、动作、手部和遮挡明确；
- L0–L3 各自的区域、方向和权重明确；未使用层无需硬塞；
- D0 保护区及低／中／高密度区明确；
- 颜色策略与底色不冲突；
- 白底明确为不透明 RGB；选择性平涂同时包含上色白名单与不填色名单；
- 双人分别拥有个人线场，共享关系场有明确目的；
- 标题只在用户要求时出现，无签名、水印和无意义字符；
- 负面约束没有误杀当前模式所需的长弧、平涂、黑底或媒介效果。

以下情形判为失败：L0 无法读出人物；高密线无法回指结构；全画面同权重；同半径卷曲／等距波浪大量重复；脸手与接触点被纹理覆盖；双人身份融合或手部归属错误。
