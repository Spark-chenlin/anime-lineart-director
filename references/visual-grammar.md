# 日系动漫乱线速写视觉语法

## 风格定位

这是一种“动漫角色设计 × 圆珠笔/数位笔分组乱线 × 高留白海报”的混合插画。视觉可信度来自有方向、有停顿的手写笔触组，而不是线条总量或涂色完整度。

## 稳定特征

### 画面结构

- 白底版本通常让纸白占约 55%–80%，人物线稿与少量色块占其余区域。
- 常见景别是极近脸部、头肩、半身、双人对视或接近动作；主体可贴边裁切。
- 横幅常把人物放在一侧，另一侧保留文字或纯白负空间；方幅与竖幅更常居中或略偏心。
- 背景只保留稀疏的大弧线、构造线、短划或少量飞白，不建立完整环境透视。

### 线条四层

1. **主轮廓线**：连续、可辨、略深；锁定脸型、发束外缘、手指、服装边界和人物接触点。
2. **结构线**：较短且方向明确；交代五官、发束、衣褶、骨点和道具轮廓。
3. **塑形乱线**：以相互分离的笔触组出现；组内线条细长、快速、重复且大致同向，跟随一束头发、一条衣褶或一个投影面，通过局部疏密形成暗部。
4. **游离试探线**：明显少于结构线，只允许短促越界、断开构造弧和局部重描；只制造手绘过程感，不参与主体识别，不连接不同物体。

主轮廓与塑形乱线必须并存。全是干净轮廓会漂成普通线稿；全是无方向乱线会失去角色与动作。塑形乱线不是连续纹理层：笔触组之间要露出纸白，不能出现大面积闭合线圈、反复回环或从头发缠到衣物的毛线团。

### 手写笔触节奏

- 每组笔触有明确的起笔区、行进方向和收笔区，线长与手压略有差异。
- 同一组允许重复重描，但不做完全平行、等距、等长的机械排线。
- 只有表面转折或两组结构相遇的暗部允许少量交叉；亮部用更少、更轻、更短的线。
- 线条跨越主轮廓时应很快停止，不能继续穿过脸、手、另一名角色或无关物体。
- 闭合圈、连续螺旋、均匀波浪线和大范围无方向长曲线属于生成噪声，不属于该风格。

### 局部清晰度

- 眼睛、虹膜高光、眉眼压力、鼻口和关键手势是最清晰区。
- 发根、深色发束与衣褶背光面是中高密度区，允许局部交叉，但每束头发和每条受力方向仍可读；不能把整个头发或服装均匀铺满。
- 面部皮肤通常以纸白表现，仅用少量短斜线表示腮红、鼻影或下颌阴影。
- 背景与轮廓外的试探线最淡、最稀且彼此断开，不应与主体争抢视觉权重。

### 色彩系统

- 白底单色：不透明纯白底；皇家蓝、克莱因蓝、蓝紫、黑、玫粉、灰棕都成立，但同一张图全程锁定一种主墨色，禁止头发、皮肤或服装固有色回流。
- 局部点色：虹膜蓝、腮红粉红、发饰红、服装小块暖红可作为 5%–15% 的点缀；不要完整铺色。
- 渐变墨线：颜色沿线条或人物区域自然迁移，不按物体分别填色。
- 黑底霓虹：背景约 70%–85% 为黑；青白线承担轮廓，蓝紫副线提供轻微色偏与余辉。

### 人物表达

- 二次元面部比例清楚，眼睛与表情比皮肤体积更重要。
- 发型是主要轮廓锚点，先定义发束大形，再以顺势重复线填充。
- 亲密双人图要明确谁位于画面左/右、脸部朝向、视线、接触点和前后遮挡；不能只写“情侣贴近”。
- 手靠近脸时要写可见手指、弯曲方向、触碰位置和遮挡范围，避免生成成无意义手团。

### 双人关系模式

双人图先完成空间骨架，再定义线条：每个人分别写画面位置、脸部朝向、可见身体范围、接触点、手部归属和遮挡顺序。接触点与两张脸各自拥有干净边界，不能用跨越两人的长曲线连接情绪。两人头发和衣服各自使用独立的笔触方向；相邻轮廓处降低乱线密度，避免人物粘连。双人图的游离试探线应少于单人图，背景只保留几条彼此断开的轻线。

## 子模式控制

### 白底单色

关键词侧重：`不透明纯白数字纸面、单色圆珠笔感、分组手写乱线、组间停顿留白、线密度塑形、无平滑填色、无固有色回流`。

### 白底局部彩色

先指定主墨线，再指定最多两种小面积点色及其落点。写明 `点色只用于局部，不进行完整上色`。

### 渐变墨线

写明 `墨线本身从蓝紫过渡到玫红/暖橙，纸白不染色`。不要写成彩色光照或虹彩皮肤。

### 黑底霓虹

写明 `黑纸反相线稿、青白主线、蓝紫轻微错位副线、有限柔光、主体内部仍由线密度区分层次`。避免体积光、金属 3D 和赛博城市背景，除非用户要求。

## 构图配方

- 单人头像：方幅或竖幅，脸占 45%–70%，头发可贴边裁切，面部留白最干净。
- 单人半身：人物占 55%–75%，外轮廓完整，服装暗部用密集线，背景留白。
- 双人亲密近景：横幅优先，两个头部形成对角或相向轴线，接触点靠近画面中心；两人分别建立轮廓和笔触方向，接触区降低线密度，禁止跨人物连续长曲线。
- 海报留白：人物占一侧 50%–65%，另一侧保留 25%–40% 纯白区，仅放低权重手写标题。
- 动态情绪：允许发丝与游离长弧线越出轮廓形成方向感，但脸与手的清晰窗口保持稳定。

## 常见失败与修正

| 失败 | 修正语言 |
|---|---|
| 过于干净，像矢量线稿 | 增加“沿结构分组重描、每组长短不一、暗部局部加密”，同时保留主轮廓和组间空隙 |
| 毛线团、回环线或均匀铺满 | 删除连续回环与跨物体长线；把乱线拆成互不相连的笔触组，每组只跟随一束头发、一条衣褶或一个投影面 |
| 乱成一团，五官消失 | 强化“眼睛鼻口、接触点和手指保持纸白清晰窗口，乱线只集中在发根、衣褶背光面和局部投影区” |
| 漂成厚涂或赛璐璐 | 强化“明暗完全由线密度形成，无平滑填色、无大面积色块、无体积厚涂” |
| 背景太满 | 强化“白底占六至八成，背景只保留极少构造弧线” |
| 像真实素描 | 强化“日系动漫面部比例、图形化虹膜、简化鼻口、非写实解剖渲染” |
| 线条机械均匀 | 强化“手压轻重变化、线长不一、局部重描、交叉方向随结构改变” |
| 点色变完整上色 | 指定点色落点和面积，并写“其余区域保持纸白与单色墨线” |
| 单色图出现头发或服装固有色 | 强化“全图统一一种主墨色，禁止物体固有色回流” |
| 白底图变透明或黑底 | 强化“不透明纯白背景，不生成透明通道，不使用反相黑底” |
| 黑底版变成 3D 霓虹 | 限制为“反相手绘线稿、有限辉光、无体积光、无金属渲染” |

## 提示词覆盖审计

交付前逐项确认：媒介和子模式、画幅与主体位置、人物身份锚点、表情与动作关系、主轮廓、分组塑形乱线、笔触方向、组间停顿留白、区域密度顺序、主墨色、背景留白和当前失败防线均已进入完整 prompt；双人图还要确认两人各自的笔触组不跨越接触区。不得凭空添加角色 IP、品牌、签名或文字。

返图出现以下任一项时判定失败：主轮廓无法独立读出；乱线无法回指具体结构；大量闭合圈或连续回环；线条从一个物体缠绕到另一个物体；面部、手部或接触点被纹理覆盖；白底单色模式出现透明/黑底、平涂或固有色回流。
